# .ai-memory/drafts/ — 工作记忆草稿（跨会话便签）

与 [../decisions/](../decisions/README.md) 的分工：**drafts 是草稿区，decisions 是定稿区**。

| | drafts/（本目录） | ../decisions/ |
|---|---|---|
| 内容 | 进行中事项、踩坑速记、待验证结论、临时上下文 | 已确认的取舍与决策 |
| 生命周期 | 随时改写、过期即删 | 只增不改，新决策标注取代 |
| 用途 | 下次会话快速恢复上下文 | 长期「为什么」档案 |

**沉淀路径**：草稿验证成熟 → 提炼进 `../decisions/`（理由）、`../playbooks/`（步骤）、`../../.ai/rules/`（约束）→ 删除草稿。

## 用法

- 团队共享便签：任意命名的 md，入库。
- 个人草稿：`*.local.md`（`.gitignore` 已忽略，不入库）。
- 一个文件一个主题；命名建议 `<主题>.md` 或 `YYYY-MM-DD-<主题>.md`。
