# .ai-memory/decisions/ — 决策记录（ADR）

**为什么这么做**记录在这里。分工（一事一处，互相不重复）：

| 内容 | 位置 |
|---|---|
| 必须遵守的约束（是什么） | `.ai/rules/` |
| 操作步骤（怎么做） | `.ai-memory/playbooks/` |
| 取舍与决策（为什么） | 本目录 |

## 格式约定

- 命名：`YYYY-MM-DD-NN-<slug>.md`（NN 为当日序号）。
- 三段式：**背景 / 决定 / 被否的选项**（被否项必须写出否决理由）。
- **只增不改（默认）**：记录一经写入不再改写；推翻旧决策 = 新增记录，并在开头标注「取代 <旧记录文件名>」。
- **整体失效例外**（见 2026-11-13-15）：结论全部被后续记录取代的记录可删除；删前确认取代记录已承接其结论与关键取舍，并同步修复指向它的引用（引用修复不算改写决策内容）。部分取代仍用新记录标注，不改写旧记录。
- 记录决策的经纬（约束、预算、外部事实），不记流水账。
