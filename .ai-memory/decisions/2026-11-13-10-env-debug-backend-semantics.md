# 语义修正：environment 段声明本地调试时后端连接的运行环境（取代 09 的键语义）

> 取代 `.ai-memory/decisions/2026-11-13-09-env-debug-target-config.md` 中 `localDebug` 的语义定义；
> 09 的位置选择、引擎只校验不消费、规则联动与回归等架构决定继续有效。

## 背景

09 把 `environment.localDebug` 实现为「前端本地 dev 的代理目标」（cloud → `WEB_API_TARGET` 指向云端网关）。
用户澄清（2026-11-13）：实际意图是「**本地调试前后端时，后端连接的运行环境**（PG/Redis/Nacos 等中间件）是本地还是云端」，
与前端代理目标无关。

## 决定

1. **语义改为后端依赖环境**：`localDebug: local`=本地中间件；`cloud`=云端 k3s 环境的中间件。
   当前值 `cloud`/`dev` 不变（用户已确认现状）；键名、枚举与引擎校验不变，测试无需改动。
2. **规则归属修正**：移除 frontend 分层规则中绑定 `WEB_API_TARGET` 的条目（前端代理机制见 vite.config.ts 注释，与本声明无关）；
   改在 backend 分层规则登记「本地调试环境」条目；project.md 指针改为「本地调试时后端连接环境」。
3. **文档同步**：配置注释与 ARCHITECTURE 表格按新语义改写；09 保留不改（决策只增不改），以本记录标注取代。

## 被否的选项

- **保留前端代理语义、另加后端键**：否决——用户意图单一明确，一段混两个维度会再次歧义；前端代理目标如确需声明另立任务。
- **直接改写 09**：否决——决策只增不改，语义变更用新记录标注取代。
