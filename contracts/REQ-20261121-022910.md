# 租户套餐模型

## 背景（钉死事实，均已实测）
- 迁移水位：platform-system 已至 V23；本 REQ 预占 V24（frontmatter）。ID 水位：sys_menu 用至 45（V22）、sys_role_menu 绑定行用至 45、sys_permission 用至 68（V19 加 68 号，V20~V23 未再加）——V24 新种子自 46/46/69 起续编。
- 种子惯例（V19/V22）：固定主键 + `ON CONFLICT (id) DO NOTHING`；UPDATE 带旧值守卫幂等；role_menu 绑定行仅 default 租户超管 role_id=1；BUTTON 节点挂叶子下；permission_code 关联 sys_permission 控制可见性；component 仅元数据。
- sys_tenant（V1:7-20+V17）无套餐字段；sys_menu 为平台目录表（无 tenant_id）；sys_role_menu 绑定表带 tenant_id（uk tenant+role+menu）；sys_permission 形状见 V1（permission_type API/http_method/http_path）。
- 菜单下发链路：MeUseCase（用户菜单树）与 RoleUseCase（角色-菜单分配）为过滤接线点；TenantUseCase/Controller 管租户 CRUD。
- 参考模型（RuoYi-Vue-Plus/yudao 套餐）：套餐绑定菜单集合 → 租户绑定套餐 → 下发时**实时过滤**（不物化拷贝，套餐变更对存量绑定租户即时生效）。
- 前端：core `systemApi`（system.ts）+ web `TenantsPage.tsx` 既有；`CrudTable`+FilterField 惯例；msw `handlers/system.ts`+`data.ts`；i18n zh/en 同步补键。
- 权限体系：API 型权限点 + BUTTON 菜单节点 + 前端 Auth 原语（V20 口径）；无权限→403 口径沿用现状。

## API
### 套餐分页 GET /admin/v1/system/tenant-packages
- 可选 keyword（packageName 模糊）+ PageQuery 分页；返回 `PageResult<AdminTenantPackageView>`：id/packageName/remark/menuCount/tenantCount/audit 列；排序 id asc；权限 system:tenant-package:list
### 套餐创建 POST /admin/v1/system/tenant-packages
- body：packageName(必填≤128)/remark(≤255)/menuIds[]（可空=空套餐）；重名→TENANT_PACKAGE_DUPLICATE；menuIds 含不存在菜单→TENANT_PACKAGE_MENU_INVALID；权限 :create
### 套餐详情 GET /admin/v1/system/tenant-packages/{id}
- 返回 AdminTenantPackageView + menuIds[]；不存在→TENANT_PACKAGE_NOT_FOUND；权限 :list
### 套餐更新 PUT /admin/v1/system/tenant-packages/{id}
- 同创建校验；menuIds 全量替换（差异同步绑定表）；权限 :update
### 套餐删除 DELETE /admin/v1/system/tenant-packages/{id}
- 被任一租户绑定→TENANT_PACKAGE_IN_USE（不删除）；否则删主行+绑定行；权限 :delete
### 租户更新 PUT /admin/v1/system/tenants/{id}（既有扩展）
- 新增可选 packageId：null=解除绑定；非法（不存在）→TENANT_PACKAGE_NOT_FOUND；其余语义与现状一致（向后兼容）
