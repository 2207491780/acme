## API
### 能力目录 GET /admin/v1/system/capabilities
- 返回 `List<AdminCapabilityView>`：id/capabilityCode/capabilityName/status；仅 status=ENABLED；排序 id asc；权限 system:tenant-package:list
### 套餐创建/更新（既有扩展）
- payload 增可选 `capabilities: string[]`（null/缺省=不改动的语义不存在——创建缺省=空集、更新缺省=空集，与 menuIds 同口径全量替换）；未知码→TENANT_CAPABILITY_INVALID
### 套餐详情（既有扩展）
- AdminTenantPackageDetailView 增 `capabilities: string[]`
### 当前租户生效能力 GET /internal/v1/system/capabilities/current
- 无权限点（internal 面，对齐服务间调用安全惯例：网关不暴露）；返回 `List<String>`；TenantContext 缺失→空数组 fail-closed（服务调用方自行决定缺省语义）
