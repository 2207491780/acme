## 确认记录（契约的权威解释；只存结论条目）
- [2026-11-21] ① 用户批量授权（同前 REQ ①）；范围=规划 WS-THEME THEME-2：圆角/灰度/色弱/语义色覆盖/内容宽度五项，不含布局模式与页签样式（THEME-4）、不含后端持久化（THEME-3）、mobile 不动。
- [2026-11-21] ② 偏好模型 v3：ThemePreferences 增 `radius: 'small'|'medium'|'large'|'full'`、`grayMode: boolean`、`weakMode: boolean`、`contentWidth: 'fluid'|'compact'`、`semanticColors: { success: string|null; warning: string|null; danger: string|null }`（null=用默认）；PREFERENCES_VERSION 2→3；migrateSettings 支持 v2→v3 无损补默认、v1 直迁 v3；blob 内嵌 schemaVersion 同步。4 个 @deprecated 投影字段保持派生不变（新字段不进投影）。
- [2026-11-21] ③ 圆角档位映射（small/medium/large/full → AntD token）：medium=现状默认（RADII 现值不动），small/large 按现有 RADII 档位比例缩放（实现提出具体值、TL 验收），full=胶囊圆角（卡/按钮/输入统一大圆角，borderRadiusContainer 类同步）。改 buildTheme token.borderRadius + components 相关联。
- [2026-11-21] ④ 灰度/色弱：作用于应用根容器 CSS filter（grayscale(1) / 色弱矩阵 SVG filter 定义在 global.css 并以 data-attribute 挂根），两者可独立开启（叠加=先灰度后色弱，CSS filter 链）；boot 脚本不处理这两项（首绘不做，避免 FOUC 复杂化——取舍记录）。图表（themeSnapshot/echarts）不做灰/弱适配（图表色不受 filter 影响可接受，浏览器 filter 覆盖 canvas 时自然生效——以实际 DOM 挂载为准）。
- [2026-11-21] ⑤ 语义色覆盖：success/warning/danger 各自预设（TONES 现值+相邻近似候选 2 档）+ColorPicker 自定义+清除恢复默认；生效面=AntD colorSuccess/colorWarning/colorError + themeSnapshot 图表语义色 + global.css 对应变量（若存在）；不覆盖 info/muted（保持体系稳定）。自定义值经 resolveAccentColor 同款合法性校验（#RRGGBB）。
- [2026-11-21] ⑥ 内容宽度：fluid=现状；compact=内容区 max-width 定值（实现按 DENSITY 惯例提出，居中），作用于 Layout 内容包裹层。
- [2026-11-21] ⑦ 抽屉：外观组扩展（圆角四档 Segmented/内容宽度两档/灰度 Switch/色弱 Switch）+ 新增「语义色」组（三行预设+自定义+清除）；即时生效+即时持久化口径与 THEME-1 一致；恢复默认含新字段。
