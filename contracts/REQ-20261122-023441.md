# BPM 流程设计器（BPM-2）

## 背景（钉死事实，均已实测 2026-11-22 主树）
- BPM-0 选型终稿（docs/bpm-engine-design-2026-11-21.md §5）：AntV X6 终稿；页面结构=/workflow/designer/:definitionId?（Palette 左拖/画布网格+对齐+框选/节点 React 组件（x6-react-shape）/连线正交+validateConnection 白名单/右 PropertyPanel AntD 表单防抖回写/工具栏=保存草稿（XML+布局 json）+校验+导入+导出+版本对比（一期可降级双栏文本 diff））；性能 ≤500 节点+async:true。
- XML 约定（§2）：交换=标准 BPMN 2.0 XML（namespace omg MODEL）+扩展 ns http://acme.dev/bpmn/ext/v1 前缀 acme:；acme: 清单=UserTask assignee（含 ${initiator}/SpEL）/candidateRoles/candidateDepts/candidateUsers/assigneeStrategy(一期 ALL)；ServiceTask serviceRef/callbackPath/retryPolicy；节点级 executionListeners(before/after)。一期白名单=StartEvent/EndEvent/XOR/AND/UserTask/ServiceTask/EmbeddedSubProcess/BoundaryEvent(timer,interrupting)；白名单外元素（CallActivity/Inclusive/多实例/Message/Signal/EventSubProcess/补偿）=二期。
- 后端 API 实际形状（platform-workflow 已交付）：ProcessDefinitionView(id wire 字符串/key/name/version/status/bpmnXml/layoutJson/createdAt/deployedAt——列表 bpmnXml 置空)；Create(key @NotBlank 64/name 128/bpmnXml 可空)；XmlSave(bpmnXml @NotBlank 仅草稿态)；6 端点权限=写面 workflow:definition:deploy(79)/读面 list(78)；分页 keyword/status/page/size PageResult；错误码 01-0001 KEY_DUPLICATE(409)/0002 XML_INVALID(400)/0003 VALIDATION_FAILED(409 明细随 data)/0004 NOT_FOUND/0005 DISABLED(409)；saveXml/deploy 校验失败=Result.fail+data 明细（区别于裸 View 信封）。
- web：routes.tsx 平铺 path 无动态段先例（findPageRoute 全等匹配）；PermissionGate fail-closed；CrudTable/useCrud 惯例；i18n resources 按域拆分；core api/workflow.ts 与 msw handlers/workflow.ts 均不存在；无 monaco/codemirror/x6 依赖；layout_json jsonb 列已预留（V1），后端无 layout 保存通道（XmlSave 仅 bpmnXml）。
- UI-SPEC 铁律：令牌单源（画布专用色如网格线/选中框需走 core 令牌新增流程）。
