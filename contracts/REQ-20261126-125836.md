# 删除多端发布演示功能

## 背景
- 「多端发布 / Multi-client releases」是项目创建之初的**演示功能**：`@acme/core` 本地存储中的发布单域（草稿→构建→测试→审批→发布、拖拽排序、批量流转、保存视图、删除撤销），Web `/releases` 页面与 Mobile releases Tab 是它的 UI。**无后端业务 API、无数据库表、无网关路由项**。
- desktop 端无该功能代码；desktop/mobile 作为多端基座（共享 core、Electron 套壳、RN 原生、租户身份）必须保留。
- 唯一后端专属引用：`ThemePreferenceValidator` 顶栏 widget 白名单中的 `release` 键（按裁决保留键、仅调整语义为 legacy-tolerant）。
- 用户约束：**不 commit、不 push、不删分支**；无子代理 spawn 工具，II-DEV 由上级代 spawn，leader 只写契约与委派单、守门。
