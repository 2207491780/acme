# BPM-5：workflow 集成 SDK + ServiceTask 委托消费 + 流程事件流 + 请假试点

## 背景（钉死事实，均已实测 2026-11-22 主树）
- 服务现状：platform-workflow（9883）双模块（api/service），网关路由 `/admin/v1/workflow/**`→lb://platform-workflow 已在；对外面=AdminProcessDefinitionController（`/admin/v1/workflow/process-definitions`：创建草稿/PUT xml/deploy/详情/分页/disable）、AdminProcessInstanceController（`/process-instances`：POST 启动/GET initiated/详情/分页/terminate|suspend|resume/history）、AdminTaskController（`/tasks`：todo|done+complete/reject/claim/unclaim/transfer/delegate）。
- **internal 面现状仅 2 端点**：`POST /internal/v1/workflow/service-tasks/{executionId}/callback`（ServiceTask 回调）与 `POST /internal/v1/workflow/timers/{timerJobId}/fire`；internal 面不经网关（workflow application.yml 注释钉死）；X-Acme-Token 内部令牌 sub=platform-workflow。
- **ServiceTask 已是 wait-state 委托**：ServiceTaskBehavior.onEnter→ExecutionEngine.dispatchServiceTask 读节点 `acme:serviceRef/callbackPath/timeoutMs/retryMaxAttempts/retryBackoffMs`（AcmeAttributes 冻结）→组 `ServiceTaskDispatchPayload(executionId, instanceId, businessKey, tenantId, nodeId, serviceRef, callbackPath, variables, traceId, attempt)`（注释钉死「BPM-5 SDK 消费侧解码契约，字段名不得变更」）→ServiceTaskDelegateClient POST `{serviceRef 解析}/{callbackPath}`（http(s) 直连或 LoadBalancerClient.choose）；失败重试经 wf_timer_job（scheduleServiceTaskRetry），耗尽挂 SERVICE_TASK_FAILED。
- **事件流现状**：WorkflowEventPublisher SPI（kernel）+ 缺省实现 LoggingWorkflowEventPublisher（仅 log.info，注释「Kafka 事件流归 BPM-5——framework-stream 装配随其契约接入」）；收集→EventPublishInterceptor @Order(70) AFTER_COMMIT 异步发布（回滚不发布）；引擎埋点已有 TASK_CREATED/INSTANCE_COMPLETED/INSTANCE_TERMINATED/INSTANCE_SUSPENDED/TIMER_FIRED/SERVICE_TASK_FAILED（WorkflowEvent 常量）；workflow-service pom 未依赖 framework-stream。
- framework-stream 消费先例：platform-infra `AuditEventConsumer`（@Bean Consumer<Message<String>>，EventEnvelopes.parse(payload, Class, jsonMapper)）；框架侧有 support/EventEnvelopes、MessageSender、StreamBridgeDispatcher。
- **SDK 惯例先例**：framework-job（support/@JobHandler 注解+JobExecutionContext record+JobHandlerRegistry+config/JobAutoConfiguration；业务侧 pom 直接 `<artifactId>framework-job</artifactId>`+显式 shedlock-provider）；跨服务 Feign client 接口惯例=放目标服务 *-api 模块（AuthorizationClient/DataScopeClient/TenantQuotaClient 均 platform-system-api）；bootstrap 本地适配器=local/ 目录 @Component @Primary + ServiceIdentityScope.runAs + LocalContractResults.ok（现 13 个，含 LocalWorkflowIdentityClient）。
- **acme-business 为空壳 pom**（modules 注释「business-content 已下线」）；platform-system 无请假/审批类实体；bootstrap 聚合 MonolithApplication @Import 五应用+scanBasePackages {com.acme.bootstrap, com.acme.platform}（business 包不在扫描面）；单体 stream 关闭+本地审计 sink。
- 迁移水位：workflow 仅 V1；MonolithContextSmokeTest 现断言=本地适配器 11 个/显式 feign clients 定义 13 个（JOB-4+TENANT-4 后口径）。
- BPM-4 审批操作 DTO：TaskCompleteRequest(Map form 可空)/TaskRejectRequest(targetNodeId,comment)/TaskTransferRequest|TaskDelegateRequest(assignee)。
