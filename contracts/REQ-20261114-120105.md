# 登录安全域——登录日志 + 在线用户管理（踢下线）

## 背景

- 后端无独立登录日志表/查询端点；现靠 `AuthSession` 会话表 + `LoginGuardRedis` 防爆破计数间接覆盖。
- 踢下线的基建已存在：Redis 撤销集 + 网关 `RevocationCheckFilter`，只差管理端点。
- 登录成功/失败路径集中在 `LoginUseCase`/`ConsumerLoginUseCase`/`LoginGuardRedis`，日志记录点可内聚（异步落库，不阻塞登录主路径）。
- 权限点种子惯例落 platform-system 迁移。

## API

> 统一响应体 `Result`；业务失败=`Result.code≠0`（HTTP 200）。

### 登录日志（platform-auth，权限 `auth:loginlog:list`）
- `GET /admin/v1/auth/login-logs`：分页（username/userType/result/时间区间筛选）。

### 在线用户（platform-auth，权限 `auth:online:list`/`auth:online:revoke`）
- `GET /admin/v1/auth/online-users`：活跃会话列表（username/ip/登录时间/最近活跃/userType），来源=AuthSession 未过期集合。
- `DELETE /admin/v1/auth/online-users/{sessionId}`：踢下线；目标不存在=`SESSION_NOT_FOUND`；目标为超管且操作者非超管=`REVOKE_SUPERADMIN_FORBIDDEN`。
