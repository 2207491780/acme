# 租户级验证码开关（系统设置扩展，默认关闭）

## 背景
- 既有事实：REQ-20261116-230354 已合入主线（bb318b6）——`sys_config` 每租户一行（tenant_id 唯一），字段 watermark_enabled/lock_idle_timeout_ms，无行租户按缺省视图生效；`GET /admin/v1/system/config` 认证即可读，PUT 经 `system:config:update`＋乐观锁（无行时 version=0 upsert）。
- B 端登录 `LoginUseCase.login()` 第 1 步无条件 `imageCaptchaUseCase.verify(captchaId, captchaCode)`；C 端（APP）为短信验证码，本需求不涉及。

- 服务身份调用先例：`TenantDirectoryGateway`（platform-auth）——UserContext.bind 服务身份主体执行 Feign 调用，finally 恢复。
- V15 编号占用：权限点至 67、role_permission 至 71、菜单至 10、role_menu 至 10（本需求无需新增权限点/菜单）。

## API
### 验证码策略公开查询（GET /admin/v1/auth/captcha-policy?tenantCode={code}）
- 公开端点（双侧豁免一致）；platform-auth 提供，内部经 Feign 查 platform-system internal 端点。
- 返回：`Result<CaptchaPolicyView>`，`CaptchaPolicyView(boolean captchaEnabled)`；下游不可用→fail-closed 返回 true＋WARN 日志；tenantCode 空白→400 参数错误。
### 内部策略查询（GET /internal/v1/system-configs/captcha-policy?tenantId={code}）
- platform-system 提供（`InternalSystemConfigController`），用例方法 `@IgnoreTenant` 按 tenant_code 直查 sys_config（该表 tenant_id 列存租户代码）；无行返回缺省 false；不经网关、openapi 不登记。
- 返回：`Result<CaptchaPolicyView>`。
### 系统配置读取/更新（GET/PUT /admin/v1/system/config，改造既有）
- `AdminSystemConfigView`/`AdminSystemConfigUpdate` 增加 `captchaEnabled`；缺省视图 captchaEnabled=false；PUT 语义与既有乐观锁/取值校验一致（boolean 无取值集校验）。
- 失败码沿用既有：SYSTEM_CONFIG_INVALID / CONCURRENCY_CONFLICT / STALE_WRITE（403/401 语义不变）。
