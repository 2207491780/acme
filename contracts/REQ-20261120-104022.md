# 页签条滚动增强＋hover 结构化预览卡

## 背景
- 现状：自绘页签条 `web/src/components/TabBar.tsx`（role=tablist，右键 Dropdown 菜单，tab=图标+label+关闭钮）＋`store/tabsStore.ts`（zustand，pinned/permanent 语义）＋`TabKeepAlive.tsx`（display:none 全量保活）。`.tabbar` 已 `overflow-x:auto`＋`scrollbar-width:none`（global.css:242~253）；tab `flex:none` 固定宽、label `max-width:160px` ellipsis、活动签底边 2px accent 线。
- 本轮决策（确认①）：**不做页签折叠/缩略**，放不下直接滚动；tab 保持 flex:none 不变。
- 令牌：global.css 取 CSS 变量镜像（var(--surface-2)/var(--accent)/var(--border) 等），视觉事实源 `packages/core/src/theme.ts`；UI 规格同步 `workspace/apps/frontend/UI-SPEC.md`。
- jsdom 无布局：溢出/滚动的行为断言依赖「判定逻辑抽纯函数」（接口在变更清单定名）＋ jsdom property override（scrollWidth/clientWidth/scrollLeft）；CSS 视觉断言沿用「CSS 源级视觉锚」模式（REQ-20261119-063129 先例）。
- 性能红线（实现约束，验收含义见 AC-18）：wheel 监听 `passive:false` 仅挂 `.tabbar` 元素且仅溢出时挂载；scroll/阴影判定 rAF 节流、布尔翻转时才写 class，不进 React state；hover 候选态放组件本地 state，不进 zustand；预览卡走 Portal（挂 body），出现/消失 opacity/transform 过渡，不触发页签列表 re-render；Ctrl/Cmd+滚轮必须放行。
- mobile（RN）无此组件、RTL 现状无 → 均不适用。

## 验收标准（规格核心；AC 是规格+追溯锚点+覆盖率核对单元；映射已由 tester 交付回填）
- AC-1 given: 页签条含 ≥2 签 when: 渲染 then: 相邻页签间显示 1px 分隔符（纯 CSS 相邻兄弟伪元素实现，不新增 DOM 节点） → should_render_adjacent_separator_by_css_pseudo_when_tabs_adjacent
- AC-2 given: 某页签 hover 或激活 when: 渲染 then: 与其相邻的分隔符淡出至不可见（opacity 0，带过渡；Chrome 降噪惯例） → should_fade_adjacent_separator_when_tab_hovered_or_active
- AC-3 given: 页签总宽 ≤ 页签条可视宽 when: 渲染 then: 无箭头按钮、无端点阴影、不挂 wheel 监听（现有溢出前行为不变） → should_render_no_arrows_and_no_wheel_listener_when_content_fits ＋ should_report_overflow_only_when_scroll_width_exceeds_client_width ＋ should_disable_both_edges_when_content_fits_client_width
- AC-4 given: 页签总宽 > 可视宽（溢出） when: 渲染 then: 两端箭头按钮出现、对应端点阴影出现；垂直滚轮在页签条上滚动时页签条横向滚动 → should_show_arrows_attach_wheel_listener_and_scroll_horizontally_when_vertical_wheel
- AC-5 given: wheel 事件携带 Ctrl 或 Cmd 修饰 when: wheel then: 不拦截不映射（放行页面缩放手势） → should_pass_through_wheel_when_ctrl_or_cmd_modifier_held ＋ should_pass_through_wheel_when_ctrl_or_cmd_pressed
- AC-6 given: 已滚动到最左（或最右） when: 渲染 then: 对应端箭头进入禁用态（视觉置灰且点击无效）、对应端阴影隐藏 → should_disable_edge_arrow_and_keep_scroll_when_already_at_edge ＋ should_disable_left_arrow_only_at_left_edge ＋ should_disable_right_arrow_only_at_right_edge ＋ should_enable_both_arrows_between_edges
- AC-7 given: 点击某端箭头 when: click then: 页签条向对应方向步进滚动（步长≈可视宽的 80%，连续点击可重复；到头后该端箭头禁用） → should_step_scroll_by_about_80_percent_of_client_width_when_arrow_clicked
- AC-8 given: activePath 变化且目标活动签在可视区外 when: 页签切换/关闭后相邻签激活 then: 页签条自动滚动使活动签完整进入可视区（scrollIntoView inline=nearest，不强制居中） → should_scroll_active_tab_into_view_nearest_when_active_path_changes
- AC-9 given: 触控板双指横滑（|deltaX| ≥ |deltaY|） when: wheel then: 不劫持不叠加二次加速，走原生横向滚动（劫持仅限 |deltaY|>|deltaX| 的纯垂直滚轮意图） → should_not_hijack_horizontal_trackpad_wheel ＋ should_pass_through_wheel_when_horizontal_intent
- AC-10 given: 非活动页签 when: hover 停留 ≥150ms then: 浮出预览卡（Portal）：页签图标＋完整标题（不受 160px 截断）＋快捷操作钮（刷新/固定·取消固定/关闭） → should_show_structured_preview_card_with_full_title_and_actions_when_hover_lingers ＋ should_invoke_reused_callbacks_with_tab_path_when_quick_action_clicked
- AC-11 given: permanent 首页签（但活动态除外） when: 预览卡 then: 无关闭钮、无固定钮（与右键菜单禁用语义一致） → should_omit_close_and_pin_actions_when_permanent_tab_hovered ＋ should_omit_close_and_pin_actions_when_tab_permanent
- AC-12 given: pinned 签 when: 预览卡 then: 固定钮显示「取消固定」、无关闭钮（pinned 不可关） → should_show_unpin_without_close_when_pinned_tab_hovered ＋ should_show_unpin_without_close_when_tab_pinned
- AC-13 given: 点击卡内快捷操作 when: click then: 复用现有回调 onRefresh/onTogglePin/onClose，语义与右键菜单一致；点击后卡关闭 → should_close_preview_card_and_tab_when_close_action_clicked ＋ should_invoke_reused_callbacks_with_tab_path_when_quick_action_clicked
- AC-14 given: 活动页签 when: hover then: 不出现预览卡 → should_not_show_preview_card_when_active_tab_hovered
- AC-15 given: 预览卡已显示 when: 指针离开页签与卡 then: 延迟关闭（防边缘抖动闪烁）；hover 候选态不写入 zustand → should_delay_close_after_pointer_leaves_and_keep_hover_state_out_of_zustand
- AC-16 given: 预览卡特性启用 when: 渲染页签 then: 页签不再设置原生 title 属性（避免与预览卡双 tooltip） → should_not_set_native_title_attribute_on_tabs_when_preview_enabled
- AC-17 given: 左（或右）端存在未显示内容 when: 溢出状态翻转 then: 对应端显示渐变阴影，出现/消失带 ≤300ms opacity 过渡 → should_show_gradient_endpoint_shadow_with_opacity_transition_under_300ms ＋ should_write_class_only_on_boolean_flip_when_scrolling
- AC-18 given: 滚动事件密集发生 when: 处理 then: 溢出/到头判定经 rAF 节流，仅布尔翻转时写 class（不逐帧写样式）；判定不触发 React 重渲染（不进 state） → should_throttle_dense_scroll_events_via_raf_without_per_frame_style_writes ＋ should_write_class_only_on_boolean_flip_when_scrolling
