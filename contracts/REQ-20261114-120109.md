## API

> 统一响应体 `Result`；业务失败=`Result.code≠0`（HTTP 200）。

### 词库管理（platform-infra，权限 `infra:sensitive:*`）
- `GET /admin/v1/infra/sensitive-words`：分页（keyword/category 筛选）；`POST`/`PUT {id}`/`DELETE {id}`：增改删（word/category/enabled）；重复词=`SENSITIVE_WORD_DUPLICATE`。

### 检测（platform-infra，权限 `infra:sensitive:match`）
- `POST /admin/v1/infra/sensitive-words/match`：body `{text, categories?}` → `Result<MatchReport>`（hitCount/hits[{word,category,start,end}]）；词库变更后自动机重建（缓存失效）。

## 验收标准（规格核心）

- AC-1 given 词库 CRUD when 操作 then 生效且重复词拒绝 → 后端 `should_createWord_when_validPayloadSubmitted` / `should_rejectDuplicateWord_when_sameWordCreatedTwice` / `should_updateWord_when_putExistingId` / `should_deleteWord_when_deleteExistingId` / `should_pageListWords_when_filterByKeywordAndCategory`；前端 `should_render_list_rows_when_sensitive_words_page_loads` / `should_submit_create_payload_when_add_and_confirm_clicked` / `should_prefill_and_submit_update_when_row_edit_clicked` / `should_delete_row_after_confirm_when_row_delete_clicked` / `should_send_keyword_filter_when_search_submitted`
- AC-2 given 含命中词文本（含变体间隔字符场景：跳过分隔符策略，实施时按①定）when match then hits 含词/类别/位置；无命中 then hitCount=0 → 后端 `should_reportHitsWithPosition_when_textContainsWord_plainAndSeparatorVariant` / `should_reportZeroHits_when_textHasNoSensitiveWord` / `should_returnBusinessError_when_matchTextEmpty` + 框架级 `SensitiveWordMatcherTest`；前端 `should_request_match_and_render_hit_word_when_trial_panel_used`
- AC-3 given 按 categories 过滤 when match then 仅统计指定类别 → 后端 `should_onlyCountSelectedCategory_when_matchFilteredByCategories` + 框架级 `SensitiveWordMatcherTest`
- AC-4 given 词库增删改 when 再次 match then 结果即时反映（自动机重建/失效生效）→ 后端 `should_stopHittingDisabledWord_when_wordDisabledAfterCreate` / `should_stopHittingDeletedWord_when_wordDeletedAfterCreate`
- AC-5 given 万级词库千字文本 when 基准测试 then 单次检测 <10ms（TL 裁决③基线）→ `framework-content/SensitiveWordMatcherBenchmarkTest`（backend R0 交付承担，tester 选项②映射）
- AC-6 given 租户隔离 when 跨租户词库/检测 then 互不可见不互串 → 后端 `should_isolateAcrossTenants_when_otherTenantQueriesAndMatches`
- AC-7 given 无权限点 when 调任一端点 then 统一拒绝 → 后端 `should_unifyReject_when_anySensitiveEndpointCalledWithoutPermission`；前端 `should_hide_write_actions_when_only_list_permission`
- AC-8 given 全部完成 when `mvn test`（PG/Redis 集成含）then 全绿 → 执行性验收，由 TL 于 III-GATE 统一执行（III-GATE 门禁4），无单独用例
