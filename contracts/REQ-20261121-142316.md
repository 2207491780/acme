## API（要点；详细语义=设计 §4）
### 定义域（6 端点）
- 创建草稿 POST /process-definitions {key,name,bpmnXml?}；PUT /{id}/xml 保存 XML（草稿态）；POST /{id}/deploy（结构校验→编译缓存→status=DEPLOYED）；GET /{id}（含 bpmnXml）；GET 分页（keyword/status 过滤，key+version 排序）；POST /{id}/disable（新实例拒绝、运行实例不受影响）
### 实例域（7 端点）
- 启动 POST /process-instances {definitionId,businessKey,variables}（校验 DEPLOYED；初始化 StartEvent→首个行为推进）；GET /{id}（实例+活跃节点+任务树+变量摘要）；分页（definitionKey/status/businessKey 过滤）；terminate/suspend/resume；GET /{id}/history（历史活动链）
### 任务域（8 端点）
- GET /tasks/todo（assignee=me 或候选含我，租户隔离）/done/initiated；complete {form?}；reject {targetNodeId?,comment?}；claim/unclaim；transfer {assignee}；delegate {assignee}（一期=转办+owner 记录，委托链单层）
### internal（2 端点）
- POST /internal/v1/workflow/timers/{timerJobId}/fire（CAS 幂等，重复 fire 拒绝）；POST /internal/v1/workflow/service-tasks/{executionId}/callback {success,result?,error?}（成功→推进；失败→重试计数/耗尽挂起）

## 验收标准（AC 骨架；用例名 tester 交付后回填）
- AC-1 given: V1+V27 when: 迁移+重放 then: 七表就绪/权限 78~82+超管绑定/幂等/坑 16 水位全库校准（历史测试 77→82 抬升清单列报）
- AC-2 given: 合法 BPMN XML when: 保存+部署 then: 结构校验过/编译缓存生成/DEPLOYED；非法（start 缺失/悬挂连线/网关无条件/id 重复/SpEL 语法错）when: 部署 then: VALIDATION_FAILED 逐条错误
- AC-3 given: 排他网关 when: 各分支条件 then: 取首个为真；无真无 default then: 挂起；default 兜底生效
- AC-4 given: 并行网关 fork 3 when: 逐支完成 then: join 计数聚合最后到达者继续、部分到达不推进
- AC-5 given: UserTask 指派各型（assignee/candidateRoles/candidateDepts/initiator）when: 启动→todo 查询 then: 按规则解析（无候选人→NO_ASSIGNEE_RESOLVED 挂起）；claim 后 assignee 生效
- AC-6 given: complete/reject/transfer/delegate 各操作 when: 提交 then: 合法跃迁生效；非法（非 assignee complete→ASSIGNEE_MISMATCH、未认领 unclaim→STATE_CONFLICT）拒绝；reject 缺省回上一 UserTask/指定回退/历史链 REJECTED 边
- AC-7 given: 并发 complete/claim 同任务 when: 竞争 then: 乐观锁+CAS 重试收敛单胜（或一致终态）
- AC-8 given: ServiceTask 委托 when: 启动 then: HTTP 下发桩收到协议体（executionId/变量快照/traceId）；回调成功→推进；失败→重试→耗尽→实例 SUSPENDED(SERVICE_TASK_FAILED)
- AC-9 given: 定时边界事件 when: 到 due_at then: fire 回调→中断当前任务（CANCELLED）→走边界分支；重复 fire→拒绝；任务先完成→timer CANCELLED+注销
- AC-10 given: 子流程 when: 进入/结束 then: 独立 scope/变量读穿透写不穿透/结束回收子树
- AC-11 given: terminate/suspend/resume when: 各操作 then: 状态机生效（SUSPENDED 拒绝新操作/恢复继续/终止后 CANCELLED 全集）
- AC-12 given: 命令失败（校验/锁冲突耗尽）when: 提交 then: 整体回滚无部分推进（库内状态与异常一致）
- AC-13 given: 编译缓存 when: disable/新版本部署 then: 失效重编译；运行期查询不触发 XML 解析
- AC-14 given: 网关路由+bootstrap 聚合 when: 配置面/冒烟 then: 路由+springdoc 分组+/internal 不暴露+第五 schema 聚合上下文启动
- AC-15 given: 历史链 when: 查询 then: ENTER/LEAVE/REJECT_EDGE/TIMER_FIRE 按序完整（异步落库不丢）
