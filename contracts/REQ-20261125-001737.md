# 多租户数据库 RLS 兜底一期（连接传播层 + system 域试点）

## 背景

- 现状隔离仅 ORM 一层：MyBatis-Flex 自动谓词 + 哨兵 `__acme_tenant_unbound__`；PG 侧无任何 RLS（已实测），原生 SQL/直连/新数据源均在防线外。
- 旁路口径：`TenantBypassScope.isActive()` 时 `FlexTenantFactory` 返回 null（忽略租户条件）；本契约在 DB 层用会话变量复刻同语义。
- 关键约束：**RLS 不拦超级用户**；`PostgreSQLContainer` 默认用户即 superuser——铁证用例必须以迁移中创建的**非超管应用角色**连接验证，否则验证无效（这是本契约成败点）。
- H2 切片测试不跑 Flyway（schema.sql 自建表），RLS 迁移不破坏切片；PG 集成经 Testcontainers 真库验证（Docker 已确认可用 29.3.1）。
- 无上下文的调度/内部链路是启用 RLS 的主要破坏面——因此试点先行（确认记录①）， pilots 范围=system 域。

## 确认记录

- [2026-11-25] ① 分两步：本 REQ=连接传播层 + system 域试点表；auth/infra/leave 扩表另立后续 REQ（用户确认）。
- [2026-11-25] ② RLS 策略口径：`USING` 与 `WITH CHECK` 均为 `tenant_id = current_setting('app.tenant_id', true) OR current_setting('app.tenant_bypass', true) = 'on'`；会话变量未设置时 current_setting 返回 NULL → 不匹配任何行（fail-closed，与 ORM 哨兵口径一致）。
- [2026-11-25] ③ 平台目录表（sys_tenant/sys_permission/sys_menu/sys_tenant_package/sys_tenant_init_template，无租户列）不启用 RLS，管理面照常全量。
- [2026-11-25] ④ 传播层仅对 jdbc:postgresql 生效（按 URL 判定），H2/其他驱动自动跳过；配置开关 `acme.tenant.rls.propagation` 默认 true，false 时行为与现状一致（逃生开关）。
- [2026-11-25] ⑤ 试点表范围=system 域全部带租户列的表（sys_user/sys_role/sys_dept/sys_position/sys_dict_type/sys_dict_item/sys_config/sys_notice/sys_message 及绑定表，以 V33 迁移枚举为准）；ENABLE+FORCE（连表 owner 也拦，superuser 例外——故验证用非超管角色）。
- [2026-11-25] ⑥ 迁移内幂等创建非超管应用角色供 PG IT 数据源使用（角色名/密码实现时定，密码不入契约；容器场景角色随库生灭）。

## 验收标准

- AC-1 given 事务内 TenantContext 绑定 when 该事务执行 SQL then 首条语句前 `SET LOCAL app.tenant_id = {tenantCode}`；given 未绑定 then 置哨兵值（不匹配任何真实租户）；given 旁路激活 then `SET LOCAL app.tenant_bypass = on`；SET LOCAL 生命周期=事务，无跨事务残留（事务结束自动清除） → 待 tester 回填
- AC-2 given V33 迁移应用（PG）when 检查试点表 then 全部 ENABLE+FORCE ROW LEVEL SECURITY 且策略口径=确认记录②，迁移幂等（重复执行不报错不重复建） → 待 tester 回填
- AC-3 铁证用例（Testcontainers PG，**非超管角色连接**）：given 绑定租户 t-1 when JdbcTemplate 直连（绕过 ORM）SELECT/UPDATE/DELETE 任意试点表 then 仅可见/可改 t-1 行，跨租户行不可见不可改 → 待 tester 回填
- AC-4 given 旁路激活（app.tenant_bypass=on）when 直连 SQL then 全租户可见可改（与 @IgnoreTenant ORM 语义一致） → 待 tester 回填
- AC-5 given 无上下文且无旁路 when 直连 SQL then 空集（fail-closed） → 待 tester 回填
- AC-6 given 平台目录表 when 管理 API 查询（如租户列表/树）then 全量可见不受影响 → 待 tester 回填
- AC-7 全量回归：H2 切片测试全绿（传播层自动跳过）；PG/Redis IT 全绿且 `Tests run: N, Skipped: 0`（SKIP 不豁免"PG 集成必须跑过"） → 待 tester 回填
- AC-8 given `acme.tenant.rls.propagation=false` when 运行 then 传播层关闭，行为与现状一致 → 待 tester 回填
