## 确认记录（契约的权威解释；只存结论条目，禁存对话原文）
- [2026-11-19] ① 架构：**脱钩 router 与渲染**——App.tsx 的 Routes 定义提取为常量 `PAGE_ROUTES: { path, element, permission? }[]`（21 条＋files 补 NAV 后 20 页）；`TabKeepAlive` 容器按 tabsStore 已开页签渲染全部页面（每 tab 一个容器 div，非激活 `display:none`），PageBoundary＋PermissionGate 逐 tab 包裹；react-router 保留（HashRouter）但仅承担「导航指令」：App 级 useLocation effect 把 location.pathname 同步进 tabsStore（navigate/openTab），渲染不再由 Route 驱动；`*` 通配与 /login 特殊语义保留在 PAGE_ROUTES 外单独处理（login 不进页签；通配 redirect 在 effect 里导航 /）。
- [2026-11-19] ② tabsStore（web/src/store/tabsStore.ts，zustand＋手写持久化 `acme.tabs.v1`＋损坏回退）：`{ tabs: {path, labelKey?, label, pinned?}[], activePath }`；openTab（存在即激活，不存在追加）、closeTab（pinned 不可关；关激活页切相邻）、closeOthers/closeRight/closeAll（pinned 保留）、togglePin、setActive；持久化恢复（会话级页签还原；无 auth 关联——登出清空）。label 来源：优先动态菜单 menuName（打开时上下文有则记），否则 nav.items.* 按 path 映射。
- [2026-11-19] ③ TabBar：自绘 tab 条组件（Header 下方独立条，pill 样式对齐 UI-SPEC；活动项 accent）；每 tab：图标(可选)＋label＋关闭钮（pinned 显固定图标）；右键 Dropdown 菜单：刷新（refreshKey 重挂该 tab 子树）/关闭/固定(取消)固定/关闭其他/关闭右侧；固定语义=pinned 前置且不可关。可点目标 ≥44 高度。
- [2026-11-19] ④ keepalive 语义：页面挂载一次（切换不卸载）；刷新动作=refreshKey++（React key 变化强制重挂=真实刷新）；数据策略=保持现状（手动刷新按钮已有），激活不自动重取；lazy 分割：PAGE_ROUTES element 改 `lazy(() => import(...))`，Suspense fallback=Skeleton 放 TabKeepAlive 容器内（每 tab 独立 Suspense，chunk 首次进入该 tab 才加载）。
- [2026-11-19] ⑤ 命令面板：Ctrl+K（既有 handler）改开 Modal 命令面板（antd Modal 顶部 20% 定位）；输入过滤三节——页面（PAGE_ROUTES + NAV label，含 /files）、页签（已开 tabs）、快捷操作（锁屏/切换主题/切换语言/新建发布单/退出登录）；键盘 ↑↓ 选择＋Enter 执行＋Esc 关闭；执行页面=「打开为页签」；既有搜索框保留原语义（Ctrl+K 改开面板——kbd 提示更新）。焦点管理：开面板 autofocus 输入、关面板还原。
- [2026-11-19] ⑥ /files 补齐：NAV 加 /files 条目（icon FileOutlined，permission infra:file:list）＋i18n `nav.items.files` zh/en（'文件管理'/'Files'）。
- [2026-11-19] ⑦ 测试兼容策略：新会话初始 tabs 仅含当前 path（renderAppAt(hash) 语义不变——单页断言兼容）；导航类测试（nav.test 动态导航/多页跳转）逐个适配（断言可能命中隐藏容器时用 container 内查询或关闭 keepalive 测试开关——提供 `window.__ACME_TABS_DISABLED__` 测试逃生口，仅测试装配使用）；10 个 App 级测试文件逐个跑通为准。
