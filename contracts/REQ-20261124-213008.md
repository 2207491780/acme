## API
### 管理端重置用户密码（PUT /admin/v1/auth/credentials/users/{userId}/password）
- 已有后端（REQ-20261114-120101 族）：body `AdminPasswordSetRequest{ password }`（1~64，非空）。
- 权限点 `auth:credential:manage`；写审计（仅 userId，凭据不入审计）。
- 语义：upsert 凭据并撤销该用户全部活跃会话；策略违反返回 `PASSWORD_POLICY_VIOLATED`；凭据域其他既有错误码沿用。
- 返回：`Result<Void>`（code="0" 成功；空数据）。

### 文件详情（GET /admin/v1/infra/files/{fileId}）
- 已有后端：返回 `Result<FileView>`（前端 core 已有 FileView 类型）；不存在 `FILE_NOT_FOUND`。
- 权限点 `infra:file:list`（与列表同点）。

### 岗位启停（PUT /admin/v1/system/positions/{positionId}/status）
- body `{ status: 'ENABLED' | 'DISABLED' }`（AdminStatusUpdate）；权限点 `system:position:update`。
- 返回 `Result<Void>`；失败沿用统一响应体（乐观锁冲突等既有码，前端回滚开关态并转译提示）。

### 角色树（GET /admin/v1/system/roles/tree）
- 返回 `Result<AdminRoleView[]>`，节点带 `children: AdminRoleView[]` 递归（根 parentId 归一 null）；后端环/重复 id/孤儿显式失败。
- 权限点 `system:role:list`（与列表同点）。

### 流程定义详情（GET /admin/v1/workflow/process-definitions/{definitionId}）
- 已有 core 封装 `workflowApi.definitions.get(definitionId): Promise<ProcessDefinitionView>`；返回 `Result<ProcessDefinitionView>`；不存在沿用既有错误码。
- 权限点与定义列表一致（workflow 定义管理既有权限面）。

### 请假发起（POST /admin/v1/leave/requests）
- body `LeaveApplyCommand{ businessKey(必填), leaveType(必填), reason, startTime(必填), endTime(必填) }`；startTime/endTime 为 ISO-8601 Instant。
- businessKey=流程实例对账锚点，调用方语义自定义：前端生成 `LEAVE-{uuid}`。
- 返回 `Result<LeaveRequestView>`：`{ id, userName, leaveType, reason, startTime, endTime, status, instanceId(可空), businessKey }`；status ∈ APPLYING→APPROVING→FILED→DONE/REJECTED。
- 无权限点（B 端用户令牌面）；失败沿用统一响应体。

### 请假详情（GET /admin/v1/leave/requests/{id}）
- 返回 `Result<LeaveRequestView>`；`{id}` 为请假单 id（wire Long）。
