## 确认记录（契约的权威解释；只存结论条目）
- [2026-11-21] ① 用户批量授权（同 REQ-010725 ①）；范围=规划 THEME-3。
- [2026-11-21] ② PUT 语义改「按域 upsert」：`AdminPreferenceView` 扩为 `messagePush`（Boolean，可空）+ `themePreference`（jsonb，可空）两域，null=不动该域，至少一域非 null 否则 400；向后兼容现有 `{messagePush}` PUT（themePreference 不被触碰）；GET 回两域（未设行 themePreference=null）。
- [2026-11-21] ③ 后端校验 fail-closed（外部输入必须运行时校验，失败不得覆盖原数据）：themePreference 顶层键白名单 schemaVersion(int)/preferences(object)/extensions(object,可省)；preferences 逐键白名单+类型+枚举+hex 正则校验（与 core 字段集对齐：mode|accent|customAccent|density|motion|radiusScale|contentWidth|semanticColorOverrides|followSystem?+扩展注册面）；extensions 仅整体结构校验（object、单键 ≤16KB、总 ≤64KB），内容透传；非法→400 既有偏好校验错误码（REQ-082531 终稿口径），不新增错误码段，原数据不动。
- [2026-11-21] ④ GET 默认值：后端不内置主题默认值（防双源漂移）——未设行 themePreference=null，前端以 core DEFAULT_PREFERENCES 兜底；messagePush 维持现有默认 false。
- [2026-11-21] ⑤ core 扩展偏好注册机制：导出 `registerPreferenceExtension(key, spec)`（spec={defaults, parse}，parse 非法降级 defaults 不抛错）+内部 PREFERENCE_EXTENSION_REGISTRY；preferences 增可选 `extensions` 键（仅当存在注册域时出现）；validateThemePreferences 对注册域调用 spec.parse 降级、未注册域透传存储；后端对 extensions 仅③的结构校验。注册面钉死为最小机制，禁止框架化过度设计。
- [2026-11-21] ⑥ web 后端持久化接线：登录成功后 GET preferences→themePreference 非 null 则经 migrateSettings 覆盖本地 preferences（后端权威）；偏好变更即时本地生效+防抖 800ms PUT themePreference；401/未登录静默停上行不报错；多窗口=后 PUT 胜（与 vben 口径一致，不引入时间戳合并）。登出不回滚本地偏好。
- [2026-11-21] ⑦ mobile 关键子集对齐：跟随系统三态（useColorScheme 解析 system，系统切换即时生效；App 入口注入 ThemeProvider，节点解析落点实现自定）；色板对齐 ACCENTS 12 预设+customAccent 同步生效（一期不做取色器 UI，customAccent 经后端同步生效并在色板以选中态呈现）；SettingsScreen 主题分段扩三态；密度仍不做（mobile 无读取点）。
- [2026-11-21] ⑧ 投影物理删除收口（THEME-1 预告）：core types.ts 4 个 @deprecated 投影字段+settingsFromPreferences+parse-state 投影 fail-closed 校验删除；parse-state legacy 扁平迁移（v1/v2 blob→v3）保留（旧数据无损窗口）；reducer legacy patch「写 preferences」语义不变；mobile 6 读取点全改写（theme.ts/hooks.ts/SettingsScreen）+theme.ts 静态 palette/onAccent 历史导出与对应测试锚点同步清理。
- [2026-11-21] ⑨ mobile 持久化：沿用 STORAGE_KEY 单 blob+schemaVersion 迁移，不新增键；登录后后端权威覆盖本地（同⑥口径），未登录/拉取失败本地缓存兜底。
- [2026-11-21] ⑩ 测试口径：后端 Testcontainers PG 集成测试（两域 upsert/兼容旧 PUT/校验拒绝矩阵/GET 默认值）；前端 core/web/mobile vitest（扩展注册机制/迁移无损/投影删除后编译面/web 接线防抖与 401 静默/mobile 三态+12 色板）；msw handlers 同步两域。tester 拆 backend/frontend 两单同轮并行，映射由 TL 回填。

## 验收标准（AC 骨架；用例名 tester 交付后回填）
- AC-1 given: PUT {messagePush} 旧形状 when: 提交 then: 成功且 themePreference 域不被触碰（兼容旧调用）
- AC-2 given: PUT 两域 when: 提交 then: GET 回显两域；再次 PUT 仅 themePreference then: messagePush 保持原值（按域 upsert）
- AC-3 given: themePreference 合法 blob when: PUT then: 存储+GET 原样回显（含 extensions 透传）；非法（未知顶层键/未知偏好键/坏枚举/坏 hex/超限）when: PUT then: 400 校验错误码且原数据不动（fail-closed 矩阵）
- AC-4 given: 未设偏好行 when: GET then: messagePush=false+themePreference=null（后端不内置主题默认值）
- AC-5 given: core registerPreferenceExtension when: 注册域+写入非法值 then: parse 降级 defaults；未注册域透传；preferences.extensions 仅注册后出现
- AC-6 given: 旧持久化 blob（v1 扁平/v2/v3 投影形态） when: 迁移 then: 无损到新 shape 且投影字段不再存在（迁移窗口保留）
- AC-7 given: 登录后端有 themePreference when: web 启动 then: 本地 preferences 被后端权威覆盖且 UI 即时生效
- AC-8 given: web 改偏好 when: 变更 then: 即时生效+防抖 800ms 单次 PUT themePreference；401 时静默停上行无未处理异常
- AC-9 given: mobile 三态 when: useColorScheme 变化 then: system 模式即时切换；手动选 light/dark 脱离 system
- AC-10 given: mobile 色板 when: 渲染 then: 12 预设全呈现；customAccent 同步生效并高亮；无取色器 UI
- AC-11 given: 投影字段删除后 when: core/web/mobile typecheck+全量 vitest then: 零残留引用（grep settings.theme/accent/density/motion 仅剩测试迁移 fixture）；Settings 页/偏好抽屉功能无回归
- AC-12 given: msw 两域 when: web 测试 then: GET/PUT 与后端契约同形（校验拒绝矩阵对齐）
