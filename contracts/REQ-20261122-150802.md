# 租户生命周期宽限期+统一配额框架（TENANT-4）

## 背景（钉死事实，均已实测 2026-11-22 主树）
- 状态机现状：sys_tenant.status 仅 ENABLED/DISABLED 双态（EnableStatus）；过期=expires_at 派生态（读时判定：登录拒绝 LoginUseCase.verifyTenantLoginable/下拉排除 listEnabled/切换校验 requireSwitchableTarget）；无宽限字段（V17 三列 contact/expires_at）；级联停用=TENANT-3 物化语义（BFS+afterCommit 撤会话）；无定时物化任务。
- 配额现状：FileUseCase.checkQuota 硬编码——sumActiveSize（sys_file 未删 size 总和）+incoming<=quota，配额值=framework-storage StorageProperties.defaultBytes 平台级单一全局值（缺省 1GiB，0=不限），无租户/套餐维度；注释自认「并发近似护栏」（非强一致）；STORAGE_QUOTA_EXCEEDED 业务码。
- 用量统计：全仓零 per-tenant usage 聚合（Dashboard 仅平台级计数）；sys_user 有 idx(tenant_id) 可支撑计数；跨租户聚合需显式旁路（@TenantId 上下文）。
- 切换视角：tenant-switch 端点已有（超管全权+互踢+channel B 审计）——本 REQ 不改造会话模型。
- 开通模板：TenantInitUseCase 动态计算授权集（保留域三前缀），无模板表——本 REQ 不动。
- 能力解析：SystemCapabilityUseCase 不校验 status/expired（闸门在登录面）——本 REQ 不改（派生态口径下闸门位置维持）。
- 前端：TenantsPage 含层级列/TreeSelect 防环/级联提示（TENANT-3 交付）；i18n tenants 键域齐备；msm fixtures 含三层样例（acme/beta/beta-south）。

## 确认记录（契约的权威解释；只存结论条目）
- [2026-11-22] ① 用户批量授权（同 REQ-010725 ①）；范围=规划 TENANT-4。
- [2026-11-22] ② 生命周期=保留双态+派生扩展（否决物化方案）：V31 sys_tenant ADD grace_until timestamptz NULL——派生态四视觉=启用中（expires_at 未到或无 expires）/宽限期（expires_at<now≤grace_until）/已过期（grace_until 也过，或 expires 过且无 grace）/已停用（status=DISABLED，正交优先）；宽限期内=仍可登录（登录响应/前端顶部提示条「租户已过期，宽限至 X」）+能力照旧；宽限到期=派生自动过期（无定时任务）；级联不作用于派生态（各租户 expires/grace 独立；父停用级联物化子 status 语义不变）。
- [2026-11-22] ③ 配额框架三级覆盖：租户覆盖（新表 sys_tenant_quota：tenant_id uk/quota_storage_bytes NULL=继承套餐/审计列）>套餐默认（V31 sys_tenant_package ADD quota_storage_bytes bigint NULL=NULL=平台缺省）>平台缺省（StorageProperties.defaultBytes 不变）；解析链 TenantQuotaUseCase.resolve(tenantCode)=租户覆盖→套餐→平台缺省；一期配额项仅存储（用户数/流程实例/调度任务数=后续 REQ）；FileUseCase.checkQuota 收编=配额值改走 TenantQuotaUseCase.resolve（其余近似护栏语义+STORAGE_QUOTA_EXCEEDED 保留）。
- [2026-11-22] ④ 用量实时性：配额硬校验实时（sumActiveSize 现状）；运营视图用量=实时查（新增 GET /tenants/{id}/usage：storageBytes/sys_file sum+userCount，@IgnoreTenant 旁路聚合；数据量小先实时，定时聚合留后续）。
- [2026-11-22] ⑤ 切换视角=不改造（现 tenant-switch 语义够运营排障；会话模型不动）。
- [2026-11-22] ⑥ 过期自动化=不引入定时物化（派生读时判定现状）；新增管理动作=update 收 graceUntil（V31 列+表单字段）；续期=既有 update expiresAt 不变。
