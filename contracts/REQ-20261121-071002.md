- [2026-11-21] ① 用户批量授权（同前 ①）；范围=规划 JOB-1（骨架+定义 CRUD+内核+选主+执行历史+注册/心跳+下发协议+一次性任务注册 API）；管理页归 JOB-3、执行器 SDK 归 JOB-2、重试/告警/分片细节归 JOB-4。
- [2026-11-21] ② **V26（platform-system）权限种子**：sys_permission 73~77（scheduler:job:list GET /admin/v1/scheduler/jobs、job:create POST、job:update PUT /{id} 与 /{id}/status 与 /{id}/trigger、job:delete DELETE、execution:list GET /admin/v1/scheduler/executions 与 /admin/v1/scheduler/executors 归 job:list）+ role_permission 77~81（default 超管）；幂等口径同 V24/V25。
- [2026-11-21] ③ **V1（scheduler 服务内）四表**：sch_job_definition（id/job_key uk/app_name/handler/trigger_type CRON|FIXED_RATE|ONCE/cron_expr/fixed_rate_ms/once_fire_at/param jsonb/retry_policy jsonb {maxAttempts,initialIntervalMs}/shard_total/timeout_ms/misfire_policy FIRE_ONCE_NOW|IGNORE/status ENABLED|DISABLED/next_fire_time 可空/审计列）；sch_executor_registry（app_name+instance_id uk/host/port/handlers jsonb/heartbeat_at/status）；sch_job_execution（definition_id/job_key/trigger_type SCHEDULE|MANUAL|RETRY|EVENT/fire_time/state PENDING|DISPATCHED|RUNNING|SUCCESS|FAILED|TIMEOUT|CANCELLED/attempt/shard_index 可空/result jsonb/error/cost_ms/trace_id/审计列；**部分唯一索引 uk(def_id,fire_time) WHERE trigger_type='SCHEDULE' AND attempt=0**）；sch_scheduler_lock（ShedLock JDBC 口径）。
- [2026-11-21] ④ API 面（12 端点见 frontmatter；语义）：创建默认 DISABLED（显式启用）；job_key 创建后不可改；更新带 @NotNull version；/status 专用端点；/trigger=MANUAL execution（权限 job:update）；executions 分页按 jobKey/state/fireTime 区间过滤；executors 列表含在线状态（心跳 stale 阈值 30s→OFFLINE）。internal 面：register/heartbeat（无权限点，Result 信封）/result 回调（状态 CAS：RUNNING→终态；PENDING/DISPATCHED 不可直接 SUCCESS）/POST /internal/v1/scheduler/jobs=一次性任务注册（trigger=ONCE@onceFireAt，jobKey 唯一，注册即返回，供 BPM-6 联动）。
- [2026-11-21] ⑤ 内核终稿：tick=1s 主循环（ShedLock JDBC 单发，lockAtMostFor=5s/lockAtLeastFor=1s，锁表 sch_scheduler_lock）；内存分层时间轮（秒 60 槽+分 60 槽）加速+每 tick DB 兜底扫描（next_fire_time<=now 未调度）；同 fire_time 幂等靠部分唯一索引；misfire 默认 FIRE_ONCE_NOW；触发后即时计算下次 next_fire_time 落库；下发=Nacos lb://{app_name} POST /internal/v1/job/executions/{executionId}/run（body：jobKey/handler/param/shardContext{index,total}/fireTime/traceId/attempt），接单超时 10s 未 200→FAILED(error=DISPATCH_TIMEOUT) 走 retry_policy（RETRY execution attempt+1，maxAttempts 耗尽→终态 FAILED）；**无在线执行器→FAILED(error=NO_EXECUTOR) 走重试**；结果异步回调推进状态；超时巡检（RUNNING 超 timeout_ms→TIMEOUT+按重试策略）；同 job 串行（上一 execution 未终态不触发下一次 SCHEDULE）。
- [2026-11-21] ⑥ 部署接入清单（随本 REQ）：gateway application.yml 路由段+springdoc 分组；seed-nacos.sh；k8s/base/platform-scheduler.yaml+kustomization；deploy.sh ALL_SERVICES+镜像映射；bootstrap 聚合（bootstrap pom 加模块；tick 循环在单体形态随 Spring 启动，ShedLock 同款）。**前端零改动**（管理页 JOB-3）。
- [2026-11-21] ⑦ 测试口径：Testcontainers PG（Testcontainers 自起容器+Kafka 惯例对齐 infra）；内核语义测试需可控时钟/短周期触发（fixed rate 1s 级任务实测推进）；选主切换测试（双实例并发 tick 仅一方触发——可用两上下文或锁竞争断言）；HTTP 下发用内嵌 MockRestServiceServer/本地桩端点验证协议与超时语义。

## 验收标准（AC 骨架；用例名 tester 交付后回填）
- AC-1 given: V1+V26 when: 迁移+重放 then: 四表就绪/权限点 73~77/超管绑定/幂等
- AC-2 given: 合法定义 when: 创建 then: 默认 DISABLED、jobKey 唯一、重复→业务错误；job_key 不可改（PUT 变更被拒或忽略——以契约为准：拒绝 SCHEDULER_JOB_KEY_IMMUTABLE）
- AC-3 given: ENABLED CRON/FIXED_RATE/ONCE 任务 when: 到达触发点 then: 生成 SCHEDULE execution 且同 fire_time 不重复（幂等）
- AC-4 given: 集群双实例 when: 并发 tick then: 同一触发仅一方执行（ShedLock 语义）
- AC-5 given: 在线执行器 when: 触发 then: HTTP 下发 PENDING→DISPATCHED→（回调）RUNNING→SUCCESS 全链路状态机正确；非法状态跃迁被拒
- AC-6 given: 下发失败/接单超时/执行回调 FAILED when: 各异常 then: 按 retry_policy 生成 RETRY execution（attempt+1），耗尽→FAILED 终态
- AC-7 given: misfire 两策略 when: 错过触发（next_fire 已过） then: FIRE_ONCE_NOW 补跑一次/IGNORE 跳到下次
- AC-8 given: RUNNING 超时 when: 巡检 then: TIMEOUT 且走重试策略
- AC-9 given: 同 job 上一 execution 未终态 when: 下一触发点到达 then: 不触发（串行）
- AC-10 given: 执行器注册/心跳/失联 when: 各操作 then: 注册入库/心跳刷新/30s 失联 OFFLINE
- AC-11 given: 无权限 when: admin 端点 then: 403 口径；无权限点变基线计数漂移（permission 72→77 断言更新属 tester 适配面）
- AC-12 given: 内部一次性任务注册 when: POST /internal/v1/scheduler/jobs then: ONCE 注册并在 fireTime 触发下发（BPM 开通位实证）
- AC-13 given: 网关路由 when: /admin/v1/scheduler/** then: 路由+springdoc 分组生效（配置面断言）；/internal 不暴露
- AC-14 given: bootstrap 聚合 when: 上下文启动 then: scheduler 模块装配成功（冒烟级）
