# 用户名唯一域收敛（sys_user 用户名租户域内唯一）

## 背景

- 现状 `sys_user.username` 全局唯一：一个租户占用 `admin` 即阻断全部租户；登录本就按 (tenantCode, username)（移动端默认租户 default 实测），域内唯一才是语义正确的模型。
- 按名查档内部契约：platform-system-api `AuthProfileClient.findByUsername(username)` → system `AuthProfileController` `GET /internal/v1/auth-profiles?username=`；消费方仅 platform-auth（`AuthProfileGateway`/`LoginUseCase`）与 acme-bootstrap `LocalAuthProfileClient`（单体直调），无其他消费者（已实测 grep）。
- 风控踢人：auth `OnlineSessionUseCase.kickAllByUsername(username)` 现为**全局**按名踢——域内唯一后同名跨租户可行，不改会误伤他租户同名用户。
- 开通初始化：`TenantInitUseCase` 合成管理员名（模板前缀+租户编码优先），撞名收敛 `USERNAME_DUPLICATED`；`UserUseCase.create` 用 `existsByUsername` 全局查重。
- 软删占名语义（唯一约束是否含 deleted 维度）以 V1 实际定义为准，本次**不改**该语义，仅在维度上加租户。

## API

### GET /internal/v1/auth-profiles（内部契约签名变更）
- 参数：`username` → `tenantCode` + `username`（均必填）。
- 语义：按 (tenant_code, username) 域内查档；未知租户或域内无此用户 → 与现状同口径失败（未命中语义不变）。
- 返回形状不变；消费方仅 auth 与 bootstrap 本地适配器（已核实）。
