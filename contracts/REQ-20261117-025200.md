# 租户机制补强＋租户页脚版权声明

## 背景
- 已实测事实（TL 定点探索 2026-11-17）：`TenantUseCase.updateStatus(Long, EnableStatus)` 仅置状态＋save，default 租户禁停保护已有；platform-system **无** system→auth 依赖（pom 无 platform-auth-api、无 openfeign runtime，system 侧现有 5 个 FeignClient 均为 auth 消费的 system 契约）；`auth_session` 自带 `tenant_id varchar(64)` 归属列（不标 @TenantId，按 tokenId 全局唯一定位）；`AuthSessionRepository` 仅 3 查询无 byTenant；`SessionRedis.revoke(tokenId, ttl)` 写 `auth:revoke:{jti}`，网关 `RevocationCheckFilter`(order 250) 每请求校验；`SessionRecorder.kickActiveSessions(userId)` 事务内底账 KICKED＋返回 RevocableToken 列表；`UserTokenIssuer.issue(userId, tenantId, roles)` 三参重载；`PermissionDecisionService` 内置角色跨租户回退经 `roleRepository.findBuiltInByRoleCodeIn`；全局 `LongToStringModule` 使 id/version wire 均为 string；V15 后编号占用：permission 66-67、role_permission 70-71、menu 10、role_menu 10；V16 仅加列无新增段位。sys_tenant 现列：id/tenant_code/tenant_name/status/remark+通用列；sys_config 现列：watermark/captcha/lock_idle+通用列。
- 前端：TenantsPage 表单无联系人/有效期；systemConfigStore state={watermarkEnabled,captchaEnabled,lockIdleTimeoutMs,version,loaded}，App.tsx L228 消费 watermarkEnabled、App.tsx L177-186 随 isAuthed load/clear；布局 footer 挂点无（仅侧栏 .sidebar-foot），Content 区可直接挂 footer；水印读 systemConfigStore 而非 meStore；登录页已用 captchaPolicy（REQ-20261117-011514）。
- 登录链路：LoginUseCase 步骤 4 租户一致性比对 profile.tenantId()；`TenantClient.listEnabled()` 为登录下拉数据源（auth 调 system）。
- 测试装配：system 侧 Testcontainers PG 单容器（REQ20261116230354 模式）；auth 侧 PG+Redis 双容器＋@MockitoBean 桩出站 Feign（REQ20261117011514 模式）；无 Docker 自动跳过、如实标注。

## API
### 租户会话批量撤销（POST /internal/v1/tenant-sessions/revocations）
- platform-auth 提供（InternalTenantSessionController＋TenantSessionRevokeUseCase）；入参 `{tenantCode}`；按 auth_session.tenant_id 枚举 status=ACTIVE 且未过期会话：底账 markKicked（事务）→ 逐个 sessionRedis.revoke(tokenId, remaining)（事务外，失败 WARN 继续）。
- 返回：`Result<TenantSessionRevokeView>`，`record TenantSessionRevokeView(int revokedCount, int failedCount)`；unknown tenant → revokedCount=0 成功返回（幂等）。
### 租户详情 by code（GET /internal/v1/tenants/by-code?tenantCode=）
- platform-system 提供；返回 `Result<TenantInternalView>`，`record TenantInternalView(String tenantCode, String tenantName, String status, Instant expiresAt)`；未知 code → 404 语义（Result 错误码 TENANT_NOT_FOUND 或既有租户错误码族）。
### 公开站点配置（GET /admin/v1/auth/public-config?tenantCode=）
- platform-auth 提供（公开豁免，双侧 public-paths 一致）；返回 `Result<TenantPublicConfigView>`，`record TenantPublicConfigView(String footerCopyright, boolean footerVisible)`；无行/未知租户 → 缺省（null,false）；system 服务不可用 → WARN＋缺省返回（页脚非安全面，fail-open）。
### 超管跨租户切换（POST /admin/v1/auth/tenant-switch）
- 认证端点；入参 `{targetTenantCode}`；返回 `Result<AdminTokenIssued>`（wire userId 为 string，同 login）；错误码：非超管 403、目标租户未知/停用/过期 → 业务错误码（TENANT_SWITCH_FAILED 族，新增 AuthError 枚举）。
### 租户 CRUD 扩展（POST/PUT /admin/v1/system/tenants…）
- AdminTenantView/Update 增 contactName/contactPhone/expiresAt（可空；expiresAt ISO-8601 字符串）；创建/更新校验：expiresAt 允许 null=长期；不校验过去时间（存量允许，登录时拒绝即可）。
### 系统配置扩展（PUT/GET /admin/v1/system/config）
- AdminSystemConfigView/Update 增 footerCopyright（可空，≤255）+ footerVisible；PUT 语义与既有乐观锁一致。
