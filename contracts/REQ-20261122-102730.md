# 流程管理页（实例监控+待办中心）（BPM-3）

## 背景（钉死事实，均已实测 2026-11-22 主树）
- 实例域 7 端点已交付（AdminProcessInstanceController）：start/get/initiated/分页（definitionKey/status/businessKey 过滤）/terminate/suspend(reason)/resume/history(List<HistoryActivityView> 非分页)。ProcessInstanceView{id(wire 字符串)/definitionId/definitionKey/businessKey/initiator/status(RUNNING|SUSPENDED|COMPLETED|TERMINATED)/suspendReason/startTime/endTime/variables/activeNodes(ActiveNodeView)/tasks(TaskItemView)}。
- 任务域 8 端点已交付（AdminTaskController）：todo/done（分页仅 page/size）/complete(form)/reject(targetNodeId?,comment?)/claim/unclaim/transfer(assignee)/delegate（委托链单层）。TaskView{id/instanceId/nodeId/nodeName/assignee/status/claimTime/completeTime/createTime}——**缺 businessKey/definitionKey/definitionName/initiator 投影**。
- 状态机：实例 RUNNING/SUSPENDED(运维挂起|SERVICE_TASK_FAILED|NO_ASSIGNEE_RESOLVED 三因)/COMPLETED/TERMINATED；任务 CREATED→CLAIMED→COMPLETED|REJECTED|CANCELLED（固定 assignee 亦先 CREATED；候选 ALL 策略可见可办）。
- 权限：V27 五码 78~82 已种子（80=http process-instances/**、81=GET tasks/**、82=POST tasks/**），**无菜单节点（V27 钉死「菜单归 BPM-3」）**；坑 16=再加权限点才抬水位，V29 纯菜单种子无权限点→计数不变。
- BPM-2 底座：WorkflowPage 列表页（注释钉死「BPM-3 在此扩实例/版本管理」）；designer 路由 matchPrefix/routePath/tabPathOf 单实例页签机制可复用；DesignerPage 画布装配硬编码交互插件（无 readOnly 参数）；NodeShape BpmnNodeData 有 error 通道可扩 running 态；i18n workflow 域 list/designer/xmlError 三子域；msw workflow handlers 仅 6 定义端点+fixtures 3 定义（实例/任务/历史 fixtures 全缺）。
- 后端校验明细 ValidationError={nodeId,rule,message}，前端 WorkflowValidationErrorDto={nodeId,field,message}——field≠rule 命名差异，BPM-3 不消费校验明细，无需处理。
- JobsPage 三 Tab+详情 Drawer 大表单先例；X6 高亮通道=cell.setData({error})+centerCell。
- 历史链 HistoryActivityView{id/nodeId/nodeType/action(ENTER|LEAVE|REJECT_EDGE|TIMER_FIRE)/assignee/startAt/endAt/detail}，ENTER/LEAVE 配对可算停留时长。
