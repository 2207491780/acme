# 框架能力接线与验证——注解推广（幂等/限流/审计）/ Spring Cache 适配 / 对象存储切换验证

## 背景

- 框架注解业务接线率低：`@Idempotent`（framework-idempotent）、`@RateLimit`（framework-ratelimit）零业务使用；`@AuditLog`（framework-audit）仅 `AuditEventController` 一处——能力"可用但少用"。
- framework-cache 自研两级缓存（Caffeine L1 + Redis L2 + pub/sub 失效）走自有 API，Spring Cache 注解（`@Cacheable/@CacheEvict`）未接。
- 对象存储 `MinioObjectStorage/OssObjectStorage` 代码就绪但环境固定 `type: local`，切换路径未在真实环境验证。
- 部署冒烟走 `.ai-memory/playbooks/conversational-cd.md`（dev 环境）。

## 验收标准（规格核心）

- AC-1 given 同一创建请求携带相同幂等键重复提交 when 第二次到达 then 返回首次结果或 `IDEMPOTENT_REJECTED`（按既有策略），无重复落库 → 待回填
- AC-2 given 写操作端点 when 调用 then 产生审计事件（Spring 事件层：action 命名/字段白名单/脱敏生效；经 MQ 落 `OpAuditEvent` 以 platform-infra 既有写端点验证，见确认记录⑤） → 用例 REQ20261114120107AuditEventIntegrationTest
- AC-3 given 超过服务内 @RateLimit 配额 when 高频调用登录/验证码 then 返回限流错误码；低于配额 then 正常 → 待回填
- AC-4 given @Cacheable 字典查询 when 同参数二次调用 then L1 命中（无 SQL）；字典变更 @CacheEvict then 失效回源 → 待回填
- AC-5 given 两级缓存 when L2 失败 then 按 L2FailurePolicy 降级不阻断；L1 失效广播跨实例生效 → 待回填
- AC-6 given storage.type=minio（dev 冒烟环境）when 上传/下载/删除/清理任务 then 全链路与 local 行为一致（对象落在 minio bucket）→ 待回填
- AC-7 given 显式 type=oss 无真实凭证 when 装配测试 then Bean 装配与配置校验正确（不发起真实请求）→ 待回填
- AC-8 given 全部接线完成 when `mvn test`（PG/Redis 集成含）与既有前端回归 then 全绿；dev 部署冒烟三件套（Pod 时间戳/镜像 tag/探活 200）→ 待回填

## 接线清单（TL 冻结 2026-11-15，依据探查实证；委派以此为准）

通用取舍：
- `/internal/**` 端点为服务间调用，一律不接注解（非用户操作）。
- B/App 端验证码端点不补审计（无业务写语义），仅补 `@RateLimit`。
- `@AuditLog.action` 命名 `<模块>.<资源>.<动作>`（既有范式 `infra.audit.list`）；`contentParams` 显式列请求体白名单字段；敏感字段（密码/凭证）不入 contentParams，依赖 mask 脱敏。
- `@Idempotent` 兼容硬约束：前端零改动、不新增幂等头 → 无头调用必须可用（幂等键=Idempotent-Key 头优先，缺省按既有实现参数指纹；若既有实现仅有 REJECT/WAIT 策略无法回退指纹，则选不拒绝放行的既有策略，禁止引入前端改动）。
- 网关 public-paths 已覆盖 B/App 登录与验证码，无需调整；服务内 `@RateLimit` 为纵深，容量与网关兜底（120/240 每分钟）错开（建议 login capacity≈30、refill≈10/s；captcha capacity≈60、refill≈20/s；onError 保持默认 FAIL_OPEN）。

### A. @AuditLog（全部非 internal 写操作端点）
- platform-auth：login(POST /admin/v1/auth/tokens, action=auth.token.login)、renew(POST …/tokens/refresh, auth.token.refresh)、logout(DELETE …/tokens/current, auth.token.logout)、kickOnlineUser(DELETE …/online-users/{sessionId}, auth.online.kick)、resetPassword(PUT …/credentials/users/{userId}/password, auth.credential.resetPassword)
- platform-auth(App)：login(POST /app/v1/auth/tokens, auth.token.login)、refresh(POST …/tokens/refresh, auth.token.refresh)、logout(DELETE …/tokens/current, auth.token.logout)
- platform-system：User create/update/delete/updateStatus/bindRoles；Role create/update/delete/updateStatus/bindPermissions/bindMenus/updateDataScope；Permission create/update/delete；Menu create/update/delete；Dept create/update/delete；Position create/update/updateStatus/delete；Tenant initialize/create/update/updateStatus；Dict createType/updateType/deleteType/createItem/updateItem/deleteItem；Message send/readAll/markRead；Notice create/update/publish/offline/delete（action=system.<资源>.<动作>）
- platform-infra：File upload/delete（infra.file.upload/remove）；Excel demoImport（infra.excel.import）；Job run（infra.job.run）

### B. @Idempotent（创建/提交类 POST）
- platform-system：User create、Role create、Permission create、Menu create、Dept create、Position create、Tenant initialize/create、Dict createType/createItem、Message send、Notice create、Notice publish
- platform-infra：File upload、Excel demoImport、Job run
- platform-auth：不接（登录有验证码+限流，且非资源创建语义）

### C. @RateLimit（公开易滥用）
- POST /admin/v1/auth/tokens（B login）、GET /admin/v1/auth/captcha（B captcha）、POST /app/v1/auth/tokens（App login）、POST /app/v1/auth/captcha（App captcha）

### D. Spring Cache 接线（AC-4/AC-5）
- framework-cache 新增 `SpringCacheManagerAdapter`（实现 Spring `CacheManager`/`Cache`，驱动既有 TwoLevelCache 两级语义：L1→L2→回源、evict 走既有 L1InvalidationBus 跨实例广播、L2 失败按 L2FailurePolicy），自动装配条件对齐既有模块条件（`@ConditionalOnAcmeModule("cache")`）。
- DictUseCase 读路径接 `@Cacheable`：getType、getItem、listItems（key 含方法参数）；pageTypes（分页查询）TL 决定不缓存（参数组合多价值低）；写路径 createType/updateType/deleteType/createItem/updateItem/deleteItem 接对应 `@CacheEvict`。

### E. 对象存储（AC-6/AC-7）
- env-stack dev overlay：仿 `k8s/base/redis.yaml`（StatefulSet+Service+探针+限额）新增 minio；`acme.storage.type=minio` 冒烟 profile（endpoint/access-key/secret-key/bucket 经 env 注入，对齐 `overlays/dev/platform-infra-storage-patch.yaml` 模式）；test/prod 不动。
- OssObjectStorage：装配/配置校验测试（显式 type=oss 不发起真实请求），真实验证延期。
