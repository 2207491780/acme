## 背景
- 已实测事实（TL 探索 2026-11-19）：MeController 仅 GET /me（MeSnapshot: user/roles/permissions/menuIds/deptName）；BCrypt 校验能力在 auth（LoginUseCase.matches 先例）；ResetPasswordUseCase 是管理员面（requireCredentialManage）+密策 8-64 位+resetCredential 返回 RevocableToken 列表；自助会话数据面已有（findByUserIdAndStatus/kickActiveSessions/kick(sessionId)——现带 auth:online:revoke 管理员权限），缺免权限点限本人的用例/端点；FileUseCase 有 bizType/bizId 列（avatar 可挂 bizType='avatar',bizId=userId）＋图片校验内置（validateImageIfNeed）；上传端点带 infra:file:upload 权限（头像上传需免权限面）；sys_user 无 avatar 列（需 V21）；通知偏好/推送 token 无任何存储；ExpoPushSender 无先例（RestClient 可用 spring-web 7；NotifyPushEvent→NotifyPushBus 扇出点是推送触发位）；expo-notifications 未装且 app.json 无 projectId（需 EXPO_PUBLIC_PROJECT_ID env 降级设计）；web 无 /profile 页（Settings 434 行 7 卡共存自然——Profile 独立页管账号、Settings 管环境偏好）、用户菜单无个人中心入口、无 Avatar 组件；mobile settings Tab 即个人中心（扩展而非新 Tab）；desktop 复用 web 零改动；迁移段位 system V21/auth V7（偏好与推送 token 属用户域放 system）；web 测试装配范本 REQ20261117011514 系列；auth IT 范本 TenantSwitch/OnlineBatchKick。
