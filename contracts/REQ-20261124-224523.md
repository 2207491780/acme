# 流程设计器视觉与画布尺寸修复（BPM-2 UI 迭代）

## 背景（钉死事实，均已实测 2026-11-24 主树 dev server）
- 尺寸问题主因：Chromium 下 x6-react-shape 在 foreignObject 内的 html wrapper `height:100%` 解析为**视口高度**而非单元格高度——实测 40×40 的 StartEvent 单元格内容渲染为 40×800 长条（1280×800 视口截图+DOM 量测），Chrome/Electron 全线受影响；所有节点类型同样溢出。
- 事件/网关渲染为矩形卡片：40×40（StartEvent/EndEvent）、50×50（XOR/AND）、36×36（BoundaryEvent）内塞"徽标+名称"行（BpmnNodeView），文本必然裁剪，且不符 BPMN 语义形状（事件=圆、网关=菱形）。
- `resolveCanvasPalette` grid alpha：light 0.08 / dark 0.07，实测暗色画布网格不可辨。
- x6-plugin-minimap 内部画布白底，暗色主题下刺眼（实测右下角 180×120 白块）。
- ValidationPanel idle 态渲染 antd Empty（约 100px 高）固定占画布下方，1280×800 下画布可视高仅 ~395px。
- DesignerPage 根高度 `calc(100vh - 160px)` 与实际可用高度不符：AppLayout=Header 64+TabBar 36+Content padding 24/60 → 应为 100vh−184px，现状产生页签内容区整页滚动条。
- autoLayout colGap=190 < EmbeddedSubProcess 宽 200、rowGap=90 < 高 120 → 导入/缺省布局节点重叠；`syncModelToGraph` 位置缺省兜底 {0,0} → 无布局数据节点全部叠于原点。
- 工具栏"刷新"按钮用 UndoOutlined 且 onClick=setModel(modelRef.current)（无实效），无 Tooltip。
- Palette drop 落点=节点左上角对齐鼠标（非居中）。
- 兼容性：core `serializeBpmnModel` 不写 BPMNDI 尺寸、layoutJson 仅存位置 → 调整 `DEFAULT_NODE_SIZES` 零兼容风险（grep core/src/workflow 无 width/height）。
- 契约约束：REQ-20261122-023441 AC-3 钉死节点=React 组件形态（x6-react-shape 保留）；REQ-20261122-102730 契约⑥ 只读渲染共用 canvasFactory（ApprovalDetailDrawer/InstanceMonitorTab 随改随益，须回归）。
- UI-SPEC 铁律：一切色值/尺寸从 @acme/core 令牌取；TONES 语义色本身低饱和可用；禁第二套色/霓虹。
- 避让：REQ-20261124-213008（在途）改 UsersPage/FilesPage/PositionsPage/RolesPage/WorkflowPage 详情抽屉/TodoCenterPage/mocks/core api 层——与本契约文件面零交集。
