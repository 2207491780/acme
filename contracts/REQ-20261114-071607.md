# 后端功能底座接线一期——文件服务（本地盘）/ Excel 通用能力 / 任务调度

## 背景

- `framework-storage` 已有 `ObjectStorage` 五操作门面（put/get/remove/exists/url，`StorageObject`/`ObjectKey`，SDK 异常统一转 BizException）与 MinIO/OSS 双实现，但**无本地盘实现、全仓库零调用**；本地 dev 环境无对象存储中间件（env-stack 仅 PG/Redis/Nacos）。
- `framework-excel` 已有 `StreamExcelReader/Writer`、`SheetMapping`、`ExcelHttpExporter`，全仓库零调用。
- `framework-job` 为 Spring `@Scheduled` + ShedLock 轻量抽象（`TaskBody`/`TaskExecutionSupport`/`TaskExecutionAspect`），零使用。
- 网关已有路由 `/admin/v1/infra/**` → `lb://platform-infra`；权限模型为接口级（`sys_permission.http_method + http_path`，种子在 platform-system 迁移）。
- 用户已确认：**本轮仅后端**（前端 core 下沉/CRUD 组件/i18n/按钮权限全部后续 REQ）；存储选型=**新增本地盘实现**（生产经同一接口切 MinIO/OSS）；导入导出**不接示范域**（仅通用能力封装 + demo 端点，不动现有业务表）。

## API

> 统一响应体 `Result`（common-core）；业务失败=`Result.code≠0`（HTTP 200），认证/权限拒绝经网关与安全层，用例勿断言 4xx。错误码在此列全，新增错误码进 common-contract 错误码布局。

### 文件服务（platform-infra）
- `POST /admin/v1/infra/files`：multipart（`file` + 可选 `bizType`/`bizId`）；白名单 contentType + 大小上限（`acme.storage.upload.max-size`，缺省 10MB；`allowed-content-types` 缺省含 xlsx/pdf/png/jpg/jpeg/txt/csv）。成功=落对象+`sys_file` 记录，返回 `Result<FileView>`（id/originalName/size/contentType/url/bizType/bizId/createdAt）。失败码：`FILE_SIZE_EXCEEDED`/`FILE_TYPE_REJECTED`。
- `GET /admin/v1/infra/files`：分页（`page/size`，可选 `bizType`/`bizId`/`keyword` 按原名模糊）→ `Result<Page<FileView>>`。
- `GET /admin/v1/infra/files/{id}`：元数据；不存在=`FILE_NOT_FOUND`。
- `GET /admin/v1/infra/files/{id}/content`：流式下载，`Content-Disposition` 原名；不存在=`FILE_NOT_FOUND`。
- `DELETE /admin/v1/infra/files/{id}`：软删记录 + `storage.remove`（幂等：已删/对象不存在均成功）。

### Excel 通用范式 demo（platform-infra，DemoRow=名称/数量/备注，无业务表）
- `GET /admin/v1/infra/excel/demo-template`：返回模板 xlsx（表头+一行示例）。
- `GET /admin/v1/infra/excel/demo-export`：确定性生成 20 行 DemoRow 导出 xlsx（同输入同输出）。
- `POST /admin/v1/infra/excel/demo-import`：multipart xlsx → 行级校验（名称非空、数量为 ≥0 数值）→ `Result<ImportReport>`（total/valid/errors[{row,field,message}]）；**validate-only 不落库**；文件非法（无法解析）=`EXCEL_PARSE_FAILED`。

### 任务调度（platform-infra）
- `GET /admin/v1/infra/jobs`：注册表列表（key/description/cron/enabled + 最近一次执行摘要）。
- `POST /admin/v1/infra/jobs/{jobKey}/run`：手动触发；ShedLock 互斥下重复触发=`JOB_ALREADY_RUNNING`；成功返回执行记录 id；执行完成与否落 `sys_job_execution`（status/started/finished/error）。
- 示例任务 `file-retention-cleanup`：清理软删超期（`acme.storage.upload.retention-days`，缺省 7）的 `sys_file` 及其对象；cron 可配（缺省每日 03:00）。
