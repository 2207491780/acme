# 按钮级权限（BUTTON 菜单节点＋前端 Auth 原语）

## 背景
- 已实测事实（TL 探索 2026-11-19）：MenuType 仅 DIRECTORY/MENU（MenuType.java 注释「按钮级不在本期」）；PermissionType 仅 API；68 个 API 权限点已是操作级粒度（system:user:create 等）——**按钮显隐可直接基于 me.permissions 实现，无需新权限点**；MeController.me() 的 menuTree=listAll 过滤 includeIds（不看 menuType）→ BUTTON 节点绑定即出现在 /me；RoleUseCase.bindMenus 现状=role_menu 全量替换（不联动 role_permission）；授权 UI 双轨（RoleMenuTree 树＋权限 Checkbox.Group 平铺 500 条）；页面按钮现用 crud.can 散点判断（无 Auth 原语）；CrudTable 行操作由页面 columns 自理（仅 createPermission prop）；buildDynamicNav 对 BUTTON（无 path 叶子）自然剔除；TenantInitUseCase.grantableMenus/grantablePermissions 按非保留域自动授予（BUTTON 节点 permission_code 非保留域会被自动授予租户管理员——开通路径无缺口）；种子段位：权限点至 68、绑定行至 72、菜单至 12、role_menu 至 12（S9 自 13/13 续编菜单与绑定，**无新权限点**）；SystemIntegrationTest 计数断言（permission 68 不变；menu 12→N；replay 列表/绑定计数联动）；menus.type i18n 无按钮文案。
- 语义定案：**BUTTON 菜单节点 = API 权限点的授权管理投影**（menu_type=BUTTON＋permission_code=既有 API 码＋无 path）；角色授权菜单树勾选 BUTTON 节点 → bindMenus 联动同步 role_permission（按节点 permission_code 映射权限点 id，差量保留非按钮来源绑定）；前端按钮显隐查 me.permissions（与后端 RequirePermissionInterceptor 同码强制）。

## 确认记录（契约的权威解释；只存结论条目，禁存对话原文）
- [2026-11-19] ① BUTTON 节点进菜单树（sys_menu menu_type=BUTTON，permission_code=既有 API 码，path/component/icon 空）；**不新建权限点**（复用 68 个既有 API 码）；种子 V20 建核心页面操作按钮节点（约 22 个：users 创建/编辑/删除/状态/角色分配、roles 创建/编辑/删除/状态/权限/菜单/数据范围、menus 创建/编辑/删除、tenants 创建/编辑/停用、dicts 类型与项增删改、depts/positions 增删改、files 删除、jobs 手动执行、notices 发布/下线/删除——以各页面实际 crud.can 调用码为准实地采集，permission_code 必须与页面代码现行码一致），menu id 自 13 起、role_menu 绑定自 13 起（超管全绑）；幂等口径同 V19。
- [2026-11-19] ② bindMenus 联动（RoleUseCase.bindMenus 改造）：入参不变（menuIds 全量替换 role_menu）；联动规则=取本次勾选中的 BUTTON 节点 permission_code 集合 → 映射 sys_permission id → 与「既有 role_permission 中由 BUTTON 来源产生的绑定」差量同步（新增/删除）；**非 BUTTON 来源的 role_permission 绑定（直接权限勾选）不动**。BUTTON 来源标记：以 sys_permission.id ∈ BUTTON 节点 permission_code 映射集判定（不引入来源列——差量计算时以「当前 BUTTON 勾选集」为权威重建该子集）。租户开通路径（TenantInitUseCase）不动（grantableMenus 自动含 BUTTON＋grantablePermissions 全量授非保留域，语义一致）。
- [2026-11-19] ③ 前端原语（packages/core）：`useHasPermission(code?: string | string[]): boolean`（meStore.permissions；未加载=false fail-closed；数组=任一命中）＋`<Auth code mode="hide"|"disable">`（disable 时包裹 children 加 disabled 语义——对 antd Button 等透传 disabled）；核心页面接线：CrudTable 行操作与新建/工具条按钮改用 `<Auth>`（Users/Roles/Menus/Tenants/Dicts/Depts/Positions/Files/OnlineUsers/Permissions/Notices/NoticesPage 等——以各页现行 crud.can 码为准一一替换，行为零变化即权限码不变）；CrudTable createPermission prop 保持。
- [2026-11-19] ④ 授权 UI：RoleMenuTree 支持 BUTTON 节点展示（antd Tree 通用——后端 menuTree 返回即显示，叶子样式可加 Tag「按钮」）；勾选联动语义由后端 bindMenus 承担（前端单树单提交不变）；MenusPage menuTypes 增 BUTTON（表单 path/component 非必填提示、permissionCode 必填校验——BUTTON 节点必须挂码）；PermissionsPage 不变。
- [2026-11-19] ⑤ 导航安全：buildDynamicNav（web/mobile）对 menuType=BUTTON 剔除（确认既有无 path 叶子剔除行为并加显式过滤注释）；/me 菜单树含 BUTTON 节点对前端 nav 构建无影响。
- [2026-11-19] ⑥ 计数联动：SystemIntegrationTest flywaySeedPresent 的 sys_menu 断言 12→实际数（V20 后实地取值）、seedScriptReplayIsIdempotent 的 replay 列表加 V20＋role_menu 计数联动（permission 计数 68 不变）；TenantInitUseCaseTest 补 BUTTON 节点授予断言。
