# 主题偏好引擎与偏好抽屉一期

## 背景（钉死事实，均已实测）
- 视觉单源：`workspace/apps/frontend/packages/core/src/theme.ts`——`ACCENTS`（6 预设：cyan/blue/violet/magenta/amber/acid）+ `ACCENT_ORDER` + `ACCENT_COMPANIONS`（渐变伴随色）+ `ON_ACCENT`（统一纯黑保证对比度）+ `DARK_NEUTRALS/LIGHT_NEUTRALS` + `resolvePalette(theme)`；注释明确禁止端侧硬编码、Web/Mobile 均从此派生。
- web 侧映射：`workspace/apps/frontend/web/src/theme.ts` `buildTheme(settings)` → AntD ThemeConfig（algorithm 按 dark/default，token.colorPrimary 等），`themeSnapshot()` 供图表；消费点 `web/src/main.tsx` `<ConfigProvider theme={buildTheme(settings)}>`。
- 状态与持久化：`web/src/store/useStore.ts` zustand——settings 在 AppState blob 内，action `UPDATE_SETTINGS`（patch 合并），整 blob 持久化 localStorage key=`acme.frontend.ops.v1`（`packages/core/src/constants.ts`）。
- 现有外观入口：`web/src/pages/Settings.tsx` 整页设置，外观卡 4 项（深色 Switch/密度 Select/6 强调色圆点/动效 Switch），i18n 键域 `settings.appearance.*`（zh-CN/en-US 两份 `packages/core/src/i18n/resources/<locale>/settings.ts`）。
- core 小 store 惯例：`packages/core/src/store/persist.ts` `loadPersistedPreference/persistPreference`（运行时校验+异常降级内存态）；水印/锁屏是租户级（systemConfigStore），不在本期。
- mobile（`mobile/src/theme.ts` + SettingsScreen 主题分段）本期不动（对齐归 THEME-3）；desktop 套壳 web 产物自动继承。
- 外部输入必须运行时校验、失败不得覆盖原数据（编码规范）；当前无统一 lint 脚本。
