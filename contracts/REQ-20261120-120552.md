# 首屏加载动画＋搜索导航增强

## 背景
- 现状：`web/index.html` 直挂 `#root`，无任何首屏加载指示——JS 加载/msw worker 启动（dev）/React 挂载期间白屏；`data-theme="dark"`、`data-accent="cyan"` 硬编码默认，持久化主题由应用接管后才有，存在暗→亮闪变窗口。
- 命令面板已存在（REQ-20261119-063129 契约⑤）：`web/src/components/CommandPalette.tsx`（Ctrl+K 开关、antd Modal top 20vh、页面/页签/快捷操作三节、↑↓/Enter/Esc、hover 选中）；Header 有搜索框＋Ctrl K 徽标（App.tsx:558/568）。缺口（用户截图对齐项）：无搜索历史（空查询显示三节全量）、无底部键位提示条、无「没有搜索历史」空态；Header 搜索框 placeholder 为旧语义文案「搜索发布单 / 版本 / 负责人…」；「页面」节未按权限过滤（无权限项也出现）。
- 权限过滤源：侧边导航 buildDynamicNav 的权限口径（App 既有权限集）；面板须与之同源（fail-closed）。
- jsdom 断言策略：splash 的行为逻辑收敛到可测纯函数 `web/src/boot.ts`（移除/淡出/最短展示），index.html 内联部分用「源级锚」断言（轮次 1/2 先例）；历史模块 localStorage 读写用运行时校验（损坏回退空，禁类型断言替代）。
- desktop 套壳同一 index.html 自动继承；mobile（RN/Expo）不适用（有自有启动屏）。
