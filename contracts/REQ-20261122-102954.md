# 子租户层级（TENANT-3）

## 背景（钉死事实，均已实测 2026-11-22 主树）
- §6.3 必答清单三问推荐答案：可见性=父不可见子数据；创建授权=一期仅平台侧创建；深度=2~3 层。
- 租户标识全链路=租户编码字符串（TenantContext/@TenantId/能力解析均按编码）；sys_user.tenant_id 存编码；username 全局唯一。
- 无 root 用户：跨租户能力=平台管理端点逐个 @IgnoreTenant 旁路（IgnoreTenantAspect 收敛）+cross-tenant-audit 审计（bypass=ROOT 标记）；fail-close 哨兵（UNBOUND_TENANT 读空集/TENANT_REQUIRED 写拒绝）。
- sys_tenant：id/tenant_code uk/tenant_name/status/remark+V17 contact/expires_at+V24 package_id（NULL=不受限）；乐观锁 version；default 租户不可停用；停用 afterCommit 撤会话。
- TenantInitUseCase 开通模板=单事务建租户+tenant_admin 角色+初始管理员+绑定（RESERVED 权限域 system:tenant:*/infra:audit:*/system:tenant-package:* 不授予）；简单 create 不建管理员。
- 套餐：package_id 单列独立绑定；菜单按套餐实时过滤（dispatchMenuIds）；能力解析 currentTenantCapabilityCodes fail-closed 空数组口径。
- 权限点 system:tenant:list/create/query/update（无 delete）；web TenantsPage CrudTable+CrudFormModal（packageId 下拉/联系人/expiresAt）；迁移水位 V28→本 REQ 占 V30（V29 已被 BPM-3 菜单种子占用）。

## 确认记录（契约的权威解释；只存结论条目）
- [2026-11-22] ① 用户批量授权（同 REQ-010725 ①）；范围=规划 TENANT-3（§6.3 三问按推荐答案钉死）。
- [2026-11-22] ② V30 迁移：sys_tenant ADD parent_id bigint NULL（NULL=顶层，逻辑引用 sys_tenant.id）+level int NOT NULL DEFAULT 1（1=顶层，上限 3）+存量回填 level=1+idx(parent_id)；tenant_code 全局唯一语义不变。
- [2026-11-22] ③ 层级规则：最大深度 3（level≤3，创建/改父时沿 parent 链校验环+深度超限报 TENANT_DEPTH_EXCEEDED/TENANT_CYCLE 错误码，归既有租户域错误码段）；改父=允许（重校验环+深度+后代整体重算 level）。
- [2026-11-22] ④ 可见性=父租户管理员不可见子租户数据（推荐采纳）：零新旁路——子租户为独立租户编码，既有 @TenantId fail-close 天然隔离；平台侧管理全部租户经既有 @IgnoreTenant 管理端点；无层级穿透机制（二期可配置穿透留待需求）。
- [2026-11-22] ⑤ 创建授权=一期仅平台侧（推荐采纳）：TenantUseCase.create 与 TenantInitUseCase（开通模板）扩展 parentId 参数（平台侧建子租户走 init 模板复用 tenant_admin+初始管理员链）；父租户管理员自助开通留二期（RESERVED 域与配额联动成本大）。
- [2026-11-22] ⑥ 配额归集口径=子租户用量独立计量不计入父租户（各租户独立配额主体）；本 REQ 只钉口径不实现（统一配额框架归 TENANT-4）。
- [2026-11-22] ⑦ 停用级联：停用父租户→afterCommit 级联停用全部后代（沿 parent 链递归）+逐租户撤会话；恢复父**不**自动恢复子（显式逐个恢复）；登录下拉/listEnabled/能力解析对 SUSPENDED 后代排除（层级感知：状态判定=自身 status 且祖先链无 SUSPENDED/DISABLED？——裁决=自身 status 即权威（级联已物化自身 status），祖先链不再动态穿透，避免解析复杂化；级联写保证一致性）。
- [2026-11-22] ⑧ 套餐=子租户独立绑定（package_id 独立，创建时可预填父值作默认但独立生效）；套餐/能力解析机制零改动。
- [2026-11-22] ⑨ API：GET /tenants list 加层级字段（parentLevel/parentId）+新增 GET /tenants/tree（全量树形，平台侧 @IgnoreTenant）；POST create/init/PUT update 收 parentId（校验③）；AdminTenantView 扩 parentId/level。权限零新增（既有 system:tenant:* 覆盖）。
- [2026-11-22] ⑩ 前端：TenantsPage 列表加层级列（level 缩进树形或 parent 列）+新建/编辑表单 parent 下拉（平台侧全量租户，排除自身与后代防环）+停用级联提示文案+tree 视图入口（可选简单树）；core api/tenants.ts 扩 tree+parentId 字段。
- [2026-11-22] ⑪ 测试口径：后端集成（层级创建/环检测/深度超限/级联停用撤会话/恢复不自动恢复子/tree 端点/init 带 parentId 建子租户管理员归子租户/套餐独立）；前端=列表层级列/parent 下拉防环排除/级联提示/msw 同形；坑 16 不涉（无新权限点）。
