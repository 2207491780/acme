## API
### 读取当前租户配置（GET /admin/v1/system/config）
- 认证即可访问（全员强制生效需读取）；租户上下文自动隔离，仅返回本租户配置。
- 无配置行 → 缺省值 { watermarkEnabled: true, lockIdleTimeoutMs: 0, version: "0" }。
- 返回：`Result<AdminSystemConfigView>`；code=0 成功；未认证 HTTP 401。
### 更新当前租户配置（PUT /admin/v1/system/config）
- 权限码 system:config:update；无权限 HTTP 403（沿用既有权限拒绝口径）。
- 载荷 { watermarkEnabled: boolean, lockIdleTimeoutMs: number, version: string }；upsert 语义（无行则建）。
- 校验：lockIdleTimeoutMs ∈ {0,60000,300000,900000}，非法 → 业务失败 code≠0（HTTP 200 信封，沿用既有参数校验口径）。
- version 乐观锁：不匹配 → 业务失败 code≠0（沿用既有 CRUD 乐观锁口径）；成功 version+1。
- 返回：`Result<AdminSystemConfigView>`（更新后视图）。
