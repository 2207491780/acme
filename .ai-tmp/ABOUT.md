# .ai-tmp/ — 临时文件区

所有 AI 工具在本仓库工作时的**临时/中间文件**（一次性脚本、草稿输出、调试日志、下载解压的中间产物等）统一放这里。

- **内容不入库**：除本说明文件外，目录内全部被 git 忽略（见根目录 `.gitignore`）。
- **目录保留**：本说明文件是目录内唯一入库文件，起占位与说明作用。
- 约束条款：`.ai/rules/ai-guidelines.md`「动手之前」第 4 条。
- 临时文件随时可删；有价值结论先按 [../.ai-memory/KNOWLEDGE.md](../.ai-memory/KNOWLEDGE.md) 的路径沉淀，再删对应文件。
