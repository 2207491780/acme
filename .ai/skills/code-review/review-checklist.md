# code-review 评审清单（唯一源）

> 四层分级：**Tier0 最高**（架构 / 设计 / 依赖 / 模块职责）→ **Tier1 业务与正确性** → **Tier2 安全 / 性能 / 并发 / 数据库 / 异常日志 / 接口 RPC MQ / 部署** → **Tier3 交 CI/L1**（编码规范 / 测试 / 文档 / 可观测）。
> 用户 6 类概要（核心功能正确性、质量健壮性、设计可维护性、安全性能、测试文档、工程规范流程）已并入上述四层，不另立第五类。
> 每条必须给出**检查要点 / 证据形态（`file:line` 或命令输出摘录）/ 负责角色 / 是否交 CI-L1**；无证据的条目降级为「疑点/待证」。
> Tier0 最高优先；**安全与架构重大缺陷一票否决**（Veto），优先级高于意见数量与其他层级。
> Tier3 由 L1/CI 或现有工具处理，蜂群只抽样复核并标「交 L1」；**禁止新增依赖**，不得把 typecheck 或测试通过表述为 lint 通过（ESLint / axe 不在锁文件，按红线不得引入）。
> 角色代号：CP=`contract-preflight`、BE=`module-inspector-be`、FE=`module-inspector-fe`、FS=`flow-simulator`、CV=`cross-contract-verifier`、IO=`impact-oracle`、QR=`quality-reviewer`、VA=`verdict-arbitrator`。

## 角色映射（优先级与节选口径）

| 角色 | 主要层级 | 节选重点 | 一票否决 |
|---|---|---|---|
| CP 契约预检 | Tier0 / Tier1 | 接口契约、版本兼容、DTO-VO 边界、返回字段脱敏、API 文档同步 | 否 |
| BE 后端模块 | Tier0 全部 + Tier1/Tier2 后端部分 | 架构分层、依赖、后端业务正确性与安全性能 | 是（后端架构重大缺陷） |
| FE 前端模块 | Tier0 前端部分 + Tier1/Tier2 前端部分 | 组件/状态/表单/防抖/路由权限/兼容/资源/内存泄漏/打包、前端 XSS 与 a11y 人工复核 | 是（前端架构重大缺陷） |
| FS 链路仿真 | Tier1 / Tier2 | 状态机、补偿、幂等、消息顺序、调用链异常 | 否 |
| CV 跨契约核验 | Tier0 / Tier1 | 三向一致、DTO-BO-DO-VO 不混用、错误码、版本兼容、字段脱敏 | 否 |
| IO 影响面预言 | Tier0 / Tier2 | 依赖引入、版本冲突、废弃漏洞、环境隔离、灰度回滚、容量、SLA、降级 | 否 |
| QR 质量审查 | Tier0 / Tier3 | 技术债、复杂度、复用重复、方法长度、扩展点；风格类只抽样并标「交 L1」 | 否 |
| VA 裁决 | 全部 | 按 Tier 分级与一票否决裁决，历史债隔离不变 | 是（汇总裁决） |

## Tier0（最高：架构与 DDD 分层、设计、依赖、模块职责）

| 检查要点 | 证据形态（file:line / 命令输出） | 负责角色 | 交 CI/L1 |
|---|---|---|---|
| 架构与 DDD 分层：Controller / Service / Repository / Domain 职责边界是否清晰，领域逻辑是否泄漏进控制器或基础设施 | `file:line`：类声明、包目录、跨层调用点 | BE / FE / CV | 否 |
| 分层边界与 DTO/BO/DO/VO 边界：DTO/BO/DO/VO 不混用、不透传实体，VO 不直接暴露持久化对象 | `file:line`：类型定义 + 方法签名 + 返回语句 | CP / CV / BE | 否 |
| 单一职责 / 上帝类 / 大函数：类与函数是否承担多个不相干职责、是否出现超大方法 | `file:line`：类/方法体行跨度 | QR / BE / FE | 否（方法长度抽样，规则交 L1） |
| 开闭原则与硬编码业务分支：新增类型/渠道是否必须改 `if`/`switch`，常量分支代替策略 | `file:line`：分支语句 + 枚举/常量定义 | BE / QR | 否 |
| 依赖方向与循环依赖：模块/包依赖是否单向，是否形成 A→B→A 环，Domain 是否反向依赖框架 | `file:line`：`pom.xml` / `package.json` / import；命令输出：依赖图 | BE / IO / QR | 否 |
| 跨层/跨模块私有能力访问：是否绕过公开契约直连私有类、包可见性被破坏、前端直连后端实现 | `file:line`：import / 可见性修饰符 / 调用点 | BE / FE / CV | 否 |
| 依赖引入：冗余依赖、版本冲突、废弃依赖、已知漏洞依赖；新增依赖是否登记 | `file:line`：依赖声明；命令输出：依赖树 | IO / BE | 部分（锁文件/漏洞扫描交 CI） |
| 第三方选型与轻量替代：第三方组件是否可用标准库/既有依赖替代，选型是否带来不成比例复杂度 | `file:line`：依赖声明 + 使用点；ADR 引用 | IO / QR | 否 |
| 配置分离：常量/地址/密钥/开关是否从代码分离，是否存在硬编码地址或密钥 | `file:line`：字面量 + 配置类；命令输出：密钥扫描 | BE / FE / IO | 部分（密钥扫描交 CI） |
| 复用与复制粘贴：同语义逻辑是否重复实现（含自定义注解、同名类与方法体字节一致），是否应上提到公共模块 | `file:line`：重复声明两处以上 + 方法体比对 | QR / BE / FE | 否 |
| 扩展点（策略/工厂/事件/SPI）合理性：扩展点是否被滥用或缺失，是否存在空壳抽象 | `file:line`：接口/实现注册点 | BE / QR | 否 |
| 技术债（TODO / FIXME / hack）登记：是否有负责人或 issue，是否临期未清理 | `file:line`：注释 + 关联 issue | QR | 部分（TODO 扫描交 CI） |
| 模块职责：模块边界是否与业务域对齐，是否存在越界承载、职责重叠或僵尸模块 | `file:line`：模块清单 + 入口类 | BE / IO | 否 |

## Tier1（业务与正确性）

| 检查要点 | 证据形态（file:line / 命令输出） | 负责角色 | 交 CI/L1 |
|---|---|---|---|
| 需求匹配：实现是否覆盖契约/验收口径，是否多做或漏做 | `file:line`：实现点 + 契约条款 | CP / BE / FE | 否 |
| 业务逻辑：`if`/`switch`/三元分支是否全覆盖，是否存在隐含 else 与遗漏枚举值 | `file:line`：分支语句 + 枚举定义 | BE / FE / FS | 部分（分支覆盖率交 CI） |
| 状态机非法跳转：状态流转是否有非法路径、越级回退、重复终态 | `file:line`：状态常量 + 变更方法 | FS / BE | 否 |
| 幂等：重复请求/重复消息/重试是否产生重复写入或重复副作用 | `file:line`：幂等键 + 去重存储；L2 探针输出 | FS / BE | 否 |
| 业务约束：业务规则（额度/配额/时间窗/唯一性）是否在服务端强制 | `file:line`：校验点 + 约束注解 | BE / CV | 否 |
| 边界值：空 / 0 / 最大 / 最小 / 临界值是否正确处理 | `file:line`：比较与运算点；命令输出：边界用例 | BE / FE | 部分（用例交 CI） |
| 补偿、回滚与告警：失败路径是否补偿、是否可回滚、是否告警而非静默 | `file:line`：catch / afterCommit / 告警调用 | FS / BE / IO | 否 |
| 分布式事务一致性：跨服务写入是否最终一致，中间态是否可观测 | `file:line`：事务边界 + 消息发送点 | FS / BE | 否 |
| 业务与数据权限：逐接口鉴权、租户隔离、越权访问是否成立 | `file:line`：鉴权注解 + 数据过滤条件 | BE / FE / CV | 否 |
| 逆向操作（删除 / 作废 / 取消）残留：缓存、消息、索引、关联数据是否清理 | `file:line`：逆向方法 + 关联写入 | FS / BE | 否 |
| 时区与时间戳：是否统一时区、时间戳单位与精度是否一致 | `file:line`：时间 API 调用 + 格式化 | BE / FE | 否 |
| 金额精度：是否使用定点数/最小单位，是否出现浮点累加 | `file:line`：金额类型 + 运算 | BE | 否 |
| 并发冲突：锁与版本控制是否覆盖更新冲突、乐观锁失败是否重试 | `file:line`：锁注解 / 版本号 / 更新条件 | BE / FS | 否 |
| 功能正确性：入参校验、入参透传清洗、返回字段泄露、空集合/null、枚举未覆盖、默认值、错误码友好性、分页校验 | `file:line`：校验器 / DTO 注解 / 返回构造；命令输出：接口用例 | CP / BE / FE | 部分（契约测试交 CI） |

## Tier2（安全 / 性能 / 并发 / 数据库 / 异常日志 / 接口 RPC MQ / 部署）

| 检查要点 | 证据形态（file:line / 命令输出） | 负责角色 | 交 CI/L1 |
|---|---|---|---|
| 安全：SQL 注入、XSS、CSRF、越权、敏感信息日志与存储、逐接口鉴权、上传校验、开放重定向、反序列化、限流、CORS、密钥硬编码、回调签名 | `file:line`：拼接/输出/鉴权/上传/回调验签点；命令输出：安全扫描 | BE / FE / CP | 部分（自动扫描交 CI；前端 XSS/a11y 人工复核） |
| 性能：N+1、大查询、循环内 IO、缓存穿透/击穿/雪崩与一致性、批量、对象创建、大对象、超时、异步、锁粒度、重复序列化、慢查询 explain | `file:line`：循环内调用 + SQL + 缓存键；命令输出：explain/压测 | BE / FE / IO | 部分（慢查询基线交 CI） |
| 并发：线程池参数、共享变量、ThreadLocal remove、异步异常、任务取消、死锁 | `file:line`：线程池定义 + ThreadLocal 使用 + 异步回调 | BE / FS | 否 |
| 数据库：DDL null/默认值/索引/注释、主键、事务范围、隔离级别、update 条件、逻辑删除、字段类型、分库分表、迁移灰度回滚、读写分离 | `file:line`：迁移脚本 + Mapper + 事务声明 | BE / IO / CP | 否 |
| 异常日志：吞异常、catch-all、业务/系统异常区分、日志级别与上下文 traceId、脱敏、堆栈、兜底、告警 | `file:line`：catch / log 语句 / 全局异常处理器 | BE / FE / FS | 部分（日志脱敏扫描交 CI） |
| 接口 / RPC / MQ：契约与版本兼容、消息大小/丢失/重复/顺序、重试死信、降级熔断、traceId、回调、第三方服务 SLA | `file:line`：契约 + 生产消费端 + 重试配置；命令输出：契约校验 | CP / CV / FS / IO | 部分（契约校验交 CI） |
| 部署：环境隔离、热更新、资源限制、灰度回滚、启停依赖、定时任务并发、资源释放 | `file:line`：部署清单 + 配置项；命令输出：发布演练 | IO / BE | 否 |
| 合规 / 审计与兜底风险：审计留痕、数据保留期、第三方合规口径、兜底路径失效风险 | `file:line`：审计写入 + 兜底分支；ADR 引用 | IO / BE / VA | 否 |
| 前端 / 移动端：组件与状态副作用、表单校验与防抖、路由权限、多端兼容、资源泄漏、打包产物 | `file:line`：组件/状态/路由/生命周期代码；命令输出：构建结果 | FE | 部分（构建交 CI） |

## Tier3（交 CI/L1：蜂群只抽样复核）

| 检查要点 | 证据形态（file:line / 命令输出） | 负责角色 | 交 CI/L1 |
|---|---|---|---|
| 命名、注释、魔法数字、方法长度、嵌套、import、格式化、常量、弃用 API | `file:line`：抽样点；命令输出：现有工具报告（无则标 SKIP(无工具)） | QR | **是（交 L1）** |
| Sonar 规则类（S7773 等）静态规则 | 命令输出：Sonar/现有检查报告；无工具标 SKIP(未接入) | QR | **是（交 L1）** |
| 自动 a11y 扫描（axe 等）：不在锁文件，禁止新增依赖，仅人工抽样与「交 L1」标记 | `file:line`：无障碍关键路径；命令输出：若已有扫描 | FE / QR | **是（交 L1）** |
| 测试覆盖率统计 | 命令输出：既有覆盖率报告 | QR | **是（交 L1）** |
| 文档格式与 markdown 规范 | 命令输出：文档检查；`file:line`：抽样 | QR | **是（交 L1）** |

> Tier3 纪律：由 L1/CI 或现有工具处理，蜂群只抽样复核；**不得把 typecheck 或测试通过表述为 lint 通过**。ESLint / axe 不在锁文件，禁止为过检查新增依赖。
