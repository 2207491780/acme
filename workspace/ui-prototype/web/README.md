# prototypes/ — 原型页（内部）

> ⚠️ 本目录全部为**代码原型**：用于评审交互与视觉方向，**不承载正式功能、不做持久化承诺**。

## 约定

1. **落点隔离**：原型页只允许放在本目录（移动端对应 `mobile/src/screens/prototypes/`），共享演示数据放 `packages/core/src/prototype/`（纯函数 + 确定性种子，两端渲染一致）。
2. **不进正式导航**：Web 原型通过 `/prototype/*` URL 访问（懒加载路由），入口仅为设置页的「原型预览（内部）」；移动端经设置页「原型预览（内部）」进入。正式 `pages/`、`NAV` 不引用任何原型组件。
3. **令牌纪律与正式页一致**：色值/尺寸从 `@acme/core` 取，禁止硬编码；无障碍要求同 UI-SPEC §7。
4. **数据为演示口径**：原型交互仅本地生效（useState），写入正式 store 的只有「读取」；涉及写操作的按钮必须提示「原型演示：仅本地生效」。

## 生命周期

```text
原型（本目录）→ 评审通过 → 成熟化：迁入正式 pages/screens、接入正式数据与持久化 → 从原型注册表删除该条目
```

- 成熟化迁移时：组件移入 `web/src/pages/`（或 `mobile/src/screens/`），业务逻辑下沉 `packages/core`（reducer/选择器），mock 数据换成真实数据源。
- 原型被否决的条目：直接从 `registry.tsx` 删除并删除对应文件。
- `registry.tsx` 是唯一登记点：索引页与路由都由它派生，新增原型只改这一个文件。
