# 原型增量二：可视化看板（V0-V6）

日期：2026-11-12
关联：`2026-11-12-02-prototype-zone.md`（原型区落点约定）

## 背景

首轮 19 项原型交付后，用户要求对「可视化看板」方向做增量设计。约束延续：零新依赖（echarts/react-native-svg 等均未在 project.md 登记）、数据确定性、两端同构、独立目录不混入正式 UI。

## 决定

新增 7 项可视化原型（registry 域「可视化看板」）：

| ID | 名称 | Web 实现 | APP 实现 |
|---|---|---|---|
| V0 | 数据大屏 | CSS/SVG 网格整合页 | 纯 View 紧凑总览 |
| V1 | 阶段管道图 | 节点链 + 连接线 | 横向点链 |
| V2 | 发布热力图 | 12/26 周格 + 原生 tooltip | 同构格（无障碍标签播报） |
| V3 | 发布漏斗 | 居中递减条 + 转化率 | 同构 |
| V4 | 应用健康雷达 | **内建 SVG 多边形** | **横向条近似**（RN 无内建 SVG，同 UI-SPEC「渐变以纯色近似」的 idiomatic 取舍） |
| V5 | 版本时间线 | 甘特横条 + 今日标线 | 同构 |
| V6 | 节点状态墙 | 格子墙 + 点击详情 | 同构（flash 提示） |

数据层：`packages/core/src/prototype/visual.ts`（热力分位、漏斗、雷达评分、甘特窗口钳制、管道链状态机、节点墙分布），7 项单测。

## 关键口径

- **漏斗排除 failed/cancelled**：漏斗为「当前在途」截面，场外单独立计数（测试锁定）。
- **管道链终态**：published 阶段标记为 done 而非 active（链路完成）。
- **图表实现**：Web 用内建 SVG/CSS，APP 用纯 View；不以「原型需要」为由引入图表库——成熟化迁移时若确需 echarts 类库，先走依赖登记流程。

## 被否的选项

- **引入 echarts / react-native-svg**：未登记依赖，违反 `.ai/rules/coding-standards.md` 边界红线；原型阶段内建实现完全够用。
- **V1 做成跨发布单依赖 DAG**：与 A6 批量编排重叠；改为单条发布单的阶段链（差异化，A6 管「单间依赖」、V1 管「单内阶段」）。

## 验证

三端 typecheck、198 项单测、web build 全绿；Web 7 新路由浏览器逐页走查 + 大屏截图核对。
